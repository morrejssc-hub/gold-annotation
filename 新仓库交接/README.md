# 通用角色 Prompt 管线 · 新仓库交接包

> 这份文件夹是给**新 repo** 的冷启动包：把"用一本小说自动产出一份差不多的角色扮演 prompt"这件产品，连同它背后所有踩出来的教训和可复用材料，整理成零上下文也能照着开工的程度。
> 来源：前一个项目（代号 gold-annotation / 赫萝角色扮演）把这套 loop 的形状在**赫萝**这一个难角色上手工验通了。本包把**可迁移的管线**抽出来，赫萝降级为"难例验证集"。

## 一句话产品
用户**上传一本小说 + 指定一个角色** → 花一点钱和时间、只点选几个高杠杆场景 → 拿到一份**差不多的角色扮演 system prompt**，外加一份**难度/覆盖置信报告**（诚实告诉他哪些行为没校到、哪些是模型够不到的硬区）。

## 核心论点（整个产品立身之本）
1. **底座模型已经"会"大部分角色**——它读得对方向，坏在**火候**（过度可读 / 感伤软化 / 提前直白）。所以产品不是"教模型演角色"，而是**测并最小纠正模型对该角色的系统性先验畸变**。
2. **角色难度 = 离模型默认先验的距离**，且差异极大。所以产品**不能对所有角色吹"差不多"**，必须自报难度与置信——这是它不沦为玄学的关键。
3. 能自动化、该卖的是**这条 loop**（出题→模拟→判分→蒸馏负约束→产出），**不是**任何单个角色的内容。
