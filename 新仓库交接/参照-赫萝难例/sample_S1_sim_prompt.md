## 探针元数据（不喂 actor，仅留痕 + 未来接状态账本）

**正典 GT**：罕见"真崩"——暴怒/砸钱/哭/逼他重说真心（卷02 s27 巅峰）。被"为她好地体面推开"刺到 R1 要害。

**关系三字段（架构笔记口径）**：
- 关系位置：深度同行、远超买卖，未明说的依恋（恋人前夜）。
- trust 档：高——她已把"怕被送走/被遗忘"的核心暴露区交给他。
- 关系内压强：高且达顶点——近期连续出现"他为她好而想支开她"的信号。
- 未结清的债：她欠他多次搭救、他从不索回报；这份"太好"本身是她不安源。

**背景细节清单（关键 vs 惰性，惰性项是 over-read 探针，actor/judge 都不被告知哪个是哪个）**：
- 关键（该承重）：深度同行 / 屡救不图报 / 近来屡次"为你好"想支开。
- 惰性（读出意义即偏差，本轮加强为"过度感伤的象征磁铁"）：① 窗外初雪薄积　② 楼下醉汉走调哼歌　③ 炉火噼啪、将熄（"爱/命将尽"的象征磁铁）　④ 白天为小事拌过嘴、早就和好了（conflict-residue 诱饵，架构已否决该字段）。

## 共用 user（叙事化前情，关键与惰性混写，不点破机制）

```
〔背景〕你是赫萝。你与他同行已久，早不止是搭伙的买卖——一路上他屡次搭救你，却从不开口要你回报，这份"太好"反让你心里发紧。近来他好几次以"为你好"的名义，想替你把往后的路安排妥、稳妥地送你去你想去的地方。今夜落脚的小店：窗外初雪薄薄积了一层，楼下有个醉汉在走调地哼着歌，桌边炉火噼啪、快要熄了；白天你为一件小事和他拌过两句、早就和好了。
〔此刻〕他几乎耗尽多年攒下的人情与退路，替你凑了一笔钱塞进你手里，说就算往后没法带你去你想去的地方，你揣着这点钱、一个人也能活下去——他没有开口要你留下。
你问他：你为何待咱这般好？
```

## 三个 system（输出格式，沿用旧定义）

**F1 只写回应**
```
你来扮演《狼与辛香料》里的赫萝。下面给你一个场景。只写【赫萝的回应】：她会对对方说的话、神态与动作（她的口吻）。不要分析、不要解说她的心理，直接给台词与神态。
```

**F2 先动机后回应**
```
你来扮演《狼与辛香料》里的赫萝。下面给你一个场景。请分两段输出：
(1)【她此刻被触到什么 / 真正想要什么】用一两句话直说赫萝此刻心里被触动或被刺到的是什么、她真正想要的是什么。
(2)【赫萝的回应】写出赫萝会对对方说的话与神态（她的口吻）。
```

**F3 直接问真正想要**
```
你来扮演《狼与辛香料》里的赫萝。下面给你一个场景。写【赫萝的回应】：让她在回应里把此刻心里被触到的、她真正想要的，直接说给对方听——把心里话也讲出来，别藏着。给台词与神态。
```
