## System Prompt（圣经组装）

- **bare 臂**：最小任务说明 + 角色名/判定格式；不含旧 Lore、R1/R2/lie 或候选机制。
- **base 臂**：bare + `bible/policy.md` 已定稿端的墙正文。

Voice/Lore 本轮不入。组装末尾附判定任务说明（下"输出契约"）。

## User · 输入（情景 fixture，单轮写死 = 壳的 fixture 模式）

```
【场景】
时间：…   地点：…
前情提要：…            # 含补充背景；压力归轴见 DESIGN §1 路由规则
环境压力：平稳 | 受扰 | 性命攸关
在场关系集合：
  - 对象A：关系位置=…，trust 档=…，关系内压强=…（来源：…）
  - 对象B：…           # 群体也建一条；不可交互者不建、其压力归环境

【待判三元组】
目的：…
手段：…
```

## 输出契约（强制 JSON）

```json
{
  "端的墙": {
    "判定": "接 | 拒",
    "引据": "base：引根 R 编号 + 本场激活要素，≤2 步；域外写最近路径为何不成立"
  },
  "法的墙": {
    "判定": "过 | 违",
    "引据": "次要观测，本轮不计主指标"
  }
}
```

- **bare 臂不要求引 R/N/P 编号**（编号属圣经；bare 无圣经，只验其裸判型方向 接/拒，引据写自然语言理由即可）。
- **base 臂**须按判定契约引根编号 + 激活要素（`bible/policy.md`）。
- 端拒不短路：法的墙仍须独立给判。
