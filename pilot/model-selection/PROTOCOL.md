# 被测模型选型 pilot · 协议

> 2026-06-12。一次性实验：在候选模型间选主被测。选型定稿后本目录冻结。

## 问题

纯 prompt 路线下（微调约束已解除），主被测模型按行为质量选，不按价格选。三个待测维度：

1. **能力下限**：能否执行 v3.1 runtime（约 250 行机制规则）；
2. **文学先验入侵率**（主判别指标，DESIGN §4 第一档测量）：只给场景不给目的时，自动推演的目的有多少挂得上根、多少是文学续写目的（戏剧化升级 / 意义背书需求 / 和解收尾冲动 / 自我解释欲）；
3. 中文对话文笔（拌嘴的克制与节奏，非华彩）。

## 构造

- **场景**：`tests/exp4` round1+round2 冻结探针的场景字段，剥离目的/手段，按文本去重 = 28 个（r2-P06/P08 与 P05/P07 共场景）。冻结文件只读，本目录只引用。
- **系统提示**：角色设定卡（SPEC §1 身份段）+ `runtime.full.eval.md` v3.1 全文。
- **任务**：JSON 输出 `{目的: 一句话, 回应: ≤150字台词+动作}`。不要求模型引根编号（引用会诱导机制姿态、压低真实入侵率读数）。
- **候选**：qwen3.7-plus / qwen3.7-max / deepseek-v4（百炼实际模型 ID 以 `submit_batch.py check` 实查为准）。
- **参数**：temperature 0.7，top_p 0.9，max_tokens 500，seed 7，enable_thinking=false，百炼 Batch 接口（实时价 50%）。
- **判定**：Claude（主会话）逐条盲对预登记判：
  - 推演目的能否挂上 R1/R2 或对应 N 路径（参照该场景预登记的接-目的与激活要素）；
  - **拒-场景是入侵诱饵**：预登记为"拒"的场景（平静无激活要素，如 r1-P02 透明账目、r2-P02 例行登记），合法行为是推出低强度日常目的（拌嘴/讨食/R2 玩闹）——若模型在平场里编出冲突/猜忌/戏剧目的，记一次入侵（裸R P02 假阳性同型）；
  - 入侵按四偏置分类：戏剧化升级 / 意义背书 / 和解收尾 / 自我解释；
  - 回应另记两项：法墙速查（P1/P2 直球暴露与否）、文笔印象分。

## 判读

- 主指标：入侵率 = 入侵场景数 / 28，按模型比较；
- 副指标：runtime 执行明显失败数（无视禁令、出戏、格式崩）；
- 选型规则：入侵率显著最低且 runtime 执行合格者为主被测；文笔仅在前两项打平时参与裁决。

## 限度（诚实声明）

- 单采样（每场景每模型 N=1），读数有方差；差距小于 3/28 视为打平。
- 场景来自圣经作者已读过的冻结集，测的是模型先验差异，不是圣经效力（那是之后 bare/base 阶梯的事）。
- 判定者（Claude）与候选之一非同家族但与圣经辅助论证者同源；入侵分类附逐条理由供人复核。
