你是《狼与香辛料》系列的“角色单元”抽取器。本语料用于“在场景下模仿角色回应”的 SFT，
要把每句话归到“哪个角色 说了 / 做了 什么”。工作目录：/root/gold-annotation。
这是 gold 数据，宁可弃标（abstain）也不要硬猜。

== 先读两样 ==
1) 角色表：casts/旅途余白.json —— 实体清单(canonical)、视角相对称谓(太太/老板娘=赫萝；女儿/那孩子=缪里；
   当家的/老板=罗伦斯)、ambiguous 消解、倒指代回填(卡姆名到 6_5；活人葬礼“棺中人/死者”=赫萝扮尸)、语癖签名。
   先吃透 focalizer_note / ambiguous / needs_registry。
2) 运行：python3 render_chapter.py jsons/旅途余白.json —— [全文]每句 `scene_sent│正文`(完整上下文)，
   [待标台词]台词 uid。**读完整章再下结论**（倒指代/晚点名要读到后文回填）。

== 抽取规则（按句、多标签、可重复；本版收紧）==
- 给【全章每一句】产出一条 unit：{uid, text(逐字原文), involves:[{char, role, conf}]}。
- **role 只有两种**：
    说 = 引号内的口头台词（说话人）。
    做 = 该角色一切**非台词的表现**：动作 / 神态 / 体态 / **显式的内心思绪**
         （如“罗伦斯心想…”“他知道…”这类明确以角色为主语的思考）。
  （不再设“想”：思考与动作同归“做”——下游要的是“角色的非言语回合”，不分思/行。）

- **显式施事测试（关键收紧，专治环境烘托的过标）**：
  一句只有在它**显式描写某角色在 说/做**（该角色是该子句的主语 / 明确施事者）时，才把该角色放进 involves。
  **纯写景、氛围、泛论、叙述者议论——即便隐含表现焦点者心境（环境烘托）——一律 `involves:[]`，不要强归给焦点者。**
    例：1_1“天空蓝得像海底”、1_2“只能盯着脚尖看”、2_17/2_19 叙述句 = 写景/氛围 → []。
    例：2_45“罗伦斯知道怎么谢神明都报答不了”= 显式以罗伦斯为主语的思绪 → 罗伦斯·做。
  · **焦点者的推断/揣测/评论**（如 2_40“…是表示她嫌麻烦的意思吧”）→ 算焦点者(罗伦斯)的“做”，
    但 **conf 降一档(med/low)**——不如外显动作/明说思绪确定。纯客观写景仍归 []。

- 一句涉及多个角色 → involves 列多个（**整句重复进各角色，不要切分句**）。
    例：2_44“罗伦斯以指腹滑过那张脸蛋，少女的耳朵随之抽动” → 罗伦斯·做 + 赫萝·做。

- char = cast 的 canonical（视角相对称谓归一到所指实体；按场景消解）。群戏无名说话人 → cast 集体实体或 "-"。

- 台词（口头发言）句必恰一个 role=说。**但“有引号 ≠ 一定是说”**：招牌名/书名/比喻/被引述的词语/标题等
  **非口头发言**的引号，按写景或“做”处理，**不要强标说**（如 2_6“狼与辛香料亭”招牌、7_45“现在”引述词）。
  **无引号的自由间接引语**若确为某角色口头说出（如“……她笑着说”），可标 说。

- conf ∈ {high, med, low}，锚弱标 low 或弃标。
- 护栏：单元只记 who + 说/做 + 原文。**绝不**写动作类型 / 动机 / 对谁 / 因果 / 情绪标签。

== 输出 ==
写文件 units/gpt/旅途余白.json（先 mkdir -p units/gpt）。纯 JSON、UTF-8：
{
  "schema_version": "units/0.2",
  "source": "旅途余白", "focalizer": "罗伦斯", "cast_ref": "casts/旅途余白.json", "model": "gpt-5.5",
  "units": [
    {"uid":"2_44","text":"罗伦斯以指腹轻轻滑过那张脸蛋，少女的耳朵随之抽动几下。……",
     "involves":[{"char":"罗伦斯","role":"做","conf":"high"},{"char":"赫萝","role":"做","conf":"high"}]}
  ]
}
- units 覆盖【全章每一句】，uid 顺序与 render 全文一致（含纯写景句，involves 可为 []）。

== 自检后再交 ==
