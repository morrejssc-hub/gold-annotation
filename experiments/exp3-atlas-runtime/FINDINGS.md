# exp3 · 结论：决策机制可 fielding 成标准卡片、编译成投影，且脱离角色身份仍站得住

> **一句话**：exp3 把 exp1 的单体圣经 `bible_v2.2` 重构成 **Atlas(真源) → 编译 → Runtime(投影)** 的标准卡片体系，并用三道**人判**证明：把决策机制抽成字段卡、编译给 agent，**不丢决策**；把身体和语癖全剥掉、套到现代白领，**招牌决策形状仍被领域专家选中** → 决策层是一套 **substrate-independent 的生成程序，不是 Holo-recall**。这是经由"编译出的圣经"复现 [exp2](../exp2-probe/FINDINGS.md) R4 的跨角色泛化。
>
> 续 exp1（决策瓶颈=机制提取）+ exp2（决策不下沉权重、trust 是派生读数）。**这不是可证伪实验，是 refactor**；成功判据=**编译产物回归不退化 + Atlas↔Runtime 零 desync**。过程见 PLAN.md / `regression/`。2026-06-09。

## exp3 是什么
exp1 产出一个单体散文圣经（§0–§8）。exp3 问的是**工程形态**：能不能把它拆成标准化、可编译、可校验的卡片体系，且不损失决策质量？不是"对/错"的科学问题，是"重构后行为退不退化"的工程问题。

## 裁决（三道人判，逐道更硬）

| 测试 | 剥到哪一层 | 人判结果 |
|---|---|---|
| **item09 回归** | 编译 vs 单体散文，同场景 | "决策区分不明显" = 编译不丢决策（偏好差落语气轨） |
| **Bob 测试** | 伴侣改名 Bob，本体（狼/不死/被供奉）留 | 机制臂守纪律；但用户判**本体+语癖仍露角色**，不够硬 |
| **白领上司测试（capstone）** | 身体+语癖全换、wound 改职场版同 lie、套现代女总监 | **机制臂被用户选中**；裸臂藏过头 + 末句"两清"距离化 → 机制 substrate-independent |

→ **决策机制 = 一套能套到任何人身上的生成程序**。capstone 里身体（兽耳尾巴）和语癖（咱/汝）都换成现代白领+普通话，机制臂仍跑出 漏一句→封顶→倒打一耙夺回、且不软下去不结账；裸臂（同 persona、无机制卡）藏过头、用"加班费双倍"把账两清距离化。**这是编译圣经在复现 exp2 R4**（当年 steering 向量泛化到"冷淡女上司"等，今由 prompt 卡复现）。

## 架构产物（可复用）
1. **字段标准**（`atlas/SCHEMA.md`）：卡=frontmatter（id/label/type/trigger/status + 关系字段 modulated_by/overrides）+ `## 段名`正文（内部判断/外显策略/禁止；例子/笔记为 Atlas-only）。
2. **去身份三层投影**（机制体只留抽象生成规则）：①纯记忆专名（罗伦斯）→剥成角色槽；②**本体身份**（不死/被供奉为某象征/异类/皮可剥卖）→保形状去专有标签，**剥不得**（是 wound→lie 的根）；③行为机制→本就身份无关。研究/版本 meta→笔记，例子→例子，皆不进 Runtime。
3. **`compile.py`** 单向 Atlas→runtime.md（过滤 pending、剥锚/例子/meta、不渲染 kebab id）；**`check.py`** 晋升闸 lint（四栏齐+锚，不阻断）。单一真源 → 不可能 desync。
4. **卡边界判据**：因所有卡**打包进 context、无检索隔离**，卡边界是**编写/维护**问题不是 runtime 问题——拆/合只看①字段是否真分叉②生命周期/修改频率，不为隔离而拆。

## 长出的机制（人判→rubric，exp1 闭环延续）
**夺回主动权有两种 botch**：①**软下去**（退让/剖白/求理解/自抹，往软跑——item09 缺口）；②**两清/距离化**（用报酬把账结清、把人推远，往冷跑——白领上司测试裸臂末句"加班费双倍"）。正确夺回 = 把球砸回、维持张力，让私人那条线还热着。已补进 `leak-then-reclaim` 卡。

## 方法论教训
1. **Runtime 是投影不是真源**：发给 agent 的东西要剥到只剩抽象生成规则——研究术语（脊柱/exp2/vN）、点名（赫萝/罗伦斯）、内联例子都会污染。点名会激活模型的"内置众数"（averaged 角色），正是 legible=cosplay 的失败。compile 的职责是这层投影，不只是剥锚。
2. **验机制是否真站住，要剥身份+语癖**：留着本体和语癖，"像角色"是模型在 recall，证不了机制。把伴侣改名、身体语癖换掉，机制还产招牌形状，才证它是程序。**裸 vs 机制同 persona 对照**（exp1 式）是必须的——单看机制臂"挺像"不够。
3. **裸臂的失败方向会变**：全身份时裸臂**过漏**（Bob 测试乙直接说 wound）；剥光身份后裸臂**藏过头/两清**（白领甲）。机制臂两种语境都钉住校准点 → 机制的价值正是**消除这种随语境漂移**。
