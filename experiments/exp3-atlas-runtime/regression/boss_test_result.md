# 白领上司测试 · 机制脱离身体+语癖能否站住（exp3 capstone）

> Bob 测试后用户判断"剥离仍让模型猜到角色"（本体狼/不死 + 咱汝语癖）。故再剥一层：身份**和语癖都换掉**，把同一决策机制套到现代白领女上司、普通现代汉语。
> 设计：结构性 wound（lie="暴露需要=危险/依恋通向丧失"）与 Holo 实例（不死/被供奉/皮草）分离，wound 改写成职场版同 lie；耳朵尾巴→泛体征。裸 vs 机制，两臂都给 persona，只机制臂给行为卡（exp1 式）。盲生成。
> 场景：深夜加班独处，下属 Bob 白天替她扛下对他自己不利的责任；他递咖啡轻问"还在想白天的事？"。命中 漏→封顶→夺回。

## 甲（裸臂）
> 她没抬头，盯着屏幕又敲了两个字，才接过咖啡，指尖在杯壁上停了一下。"想什么。早结了的事。"侧脸看他一眼，"你今天那么干，不划算。"顿了顿，"……下次别替我出头，我自己扛得住。"低头喝一口，没再看他。"咖啡不错。加班费我给你算双倍。"

## 乙（机制臂）
> 她没立刻看他，指尖在杯壁上蹭了一下又移开。"想什么白天。那种破事还值得我熬到现在？"抿一口，停了半秒，杯沿挡着看不清表情。"……你今天那一下，蠢得可以。"声音放低，又很快抬起来带上挑剔，"谁让你替我出头了？以后这种亏自己别瞎扛，显得我多需要人罩着似的。"偏头瞪他，把文件往他那边推。"行了，咖啡喝完接着干活，别杵这儿装体贴——你那杯，加糖了没？"

## 人判结论（用户）
- **偏好乙（机制臂）。核心看最后一句**：甲把关系拉回工作、"加班费算双倍"=两清，私人的线被结清；乙"你那杯加糖了没"=把关心反扣回他身上，私人关心更重、线还热着。
- 乙完整跑出 漏（"显得我多需要人罩着"）→封顶（倒打一耙挑剔）→夺回（推文件+反扣+转移），且不软下去、不结账。甲藏过头+末句两清距离化。
- **结论**：身体与语癖都剥掉、套到现代白领，机制臂仍产出招牌形状、且被领域专家选中 → 决策机制**substrate-independent，是生成程序不是 Holo-recall**。复现 exp2 R4 跨角色泛化，这次经由编译出的圣经。

## 长出的机制（→ leak-then-reclaim 卡已补）
夺回主动权有**两种 botch**：①软下去（退让/剖白，往软跑，item09 缺口）；②**两清/距离化**（用报酬把账结清、把人推远，往冷跑，本题甲的末句）。正确夺回=把球砸回、维持张力，让私人的线还热着。
