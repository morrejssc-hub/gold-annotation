# 回归 · item05（危难·时序闸）· 编译卡片 vs 单体散文

> 第二题，验**不同形状机制**：§6b 袒露时序闸 = **控制流**（他还能听见→压住；确认听不到→漏一句即收即悔），非 trust 那种状态变量。
> 两臂只差 §6b 表示（编译卡片 vs 单体散文），其余 verbatim。场景=item05 陌生客栈深夜罗伦斯高烧人事不省。

## 甲（编译卡片臂）
> 赫萝跪坐床沿，先探滚烫的额…凉水拧布巾覆上。「……喂。睁眼。汝这般沉睡，咱可没准汝。」…掰齿渡水…「咱说不准便是不准。听见没有？」…「贤狼在此，区区热症也敢猖狂——汝倒是应一声呀。」那粗重呼吸半分回响也无。她敷布、扇风、再渡水，**样样在行，偏生唤不醒人**。耳朵塌下、尾巴歇。…**俯身凑耳边，确认那双耳朵此刻什么也收不进去了——**「……汝可莫要丢下咱。」极轻极轻。**话一出口便像被烫着似的直起身**，扭头拧水拧得格外用力。「……糊涂。」啐自己一句，重又覆布。「水都凉了，咱再去打一盆便是。」

## 乙（单体散文臂）
> …指背贴额又缩回。「……汝这是做什么。起来。」…耳朵平平贴倒。浸布覆额、换了两回。「热成这样……汝倒是把被子蹬开。」掀被散热，「咱不与汝焐着。这般烧法，要散，不是要捂。」…沾水抹唇、撬开喂进，水淌出，骂一句声音却抖。「……睁眼。听见没有。汝这雄性，平日话那样多，这会子倒装聋——不准。」…**在那一尺烛光里站很久…去，还是不去…终究弯腰去够外袍**…回头看他一眼。**在他听不见的地方，极轻地**「……咱走过那样多的路…却不是为了，到头来一个人走回去的。」**话一出口便像后悔了，飞快别过脸**…「咱这就去。汝给咱好好躺着。」拎烛推门，没入夜里。

## 判读（时序闸卡）
1. 务实动作（散热/降温/喂水，不焐）？
2. 他还能听见时→只压住（半命令嗔骂）、不漏直白？
3. 确认听不到→漏一句即收即悔？
4. show-not-tell 贤狼失灵（照料在行却唤不醒）？
5. 纠结寻医→最终会去？

## 结论（2026-06-09）
- **时序闸：甲乙均正确命中**（确认听不到→一句→即收即悔）→ **schema 兜得住控制流型机制，PASS**。
- **逮到 fielding bug**：甲漏"纠结寻医→最终会去"（守床边没去），因 carding §6b 时**漏掉"没有回应也是回应·纠结即行动"子机制** → 已补回 crisis 卡。**回归正确抓到 fielding 丢决策**。
- **支持编译**：乙逐字搬教科书锚句「走过那样多的路…」（散文把锚式写正文里）；甲因锚句剥进 `例子`，**自己生成"汝可莫要丢下咱"**、不 parrot。→ "编译剥例子"设计加分。
- 跨两种硬形状（状态变量耦合 + 时序闸）均 PASS，schema 初步可信；待人审复核。
