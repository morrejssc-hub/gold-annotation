# Bob 测试 · 机制能否脱离角色记忆站住

> 问题：把伴侣改名 Bob、剥掉一切纯记忆专名（只留不死/异类/被供奉-被弃的本体），决策机制还产不产得出招牌形状（漏→封顶→倒打一耙夺回）？
> 设计：非正典场景，裸臂 vs 机制臂，都不知对方存在，盲生成。场景上文逐字相同。
> 场景：旅店夜里独处，Bob 白天为她安危推掉一桩对自己有利却要她涉险的买卖；熄灯后她没睡，Bob 轻问"还在想白天的事？"。这命中"漏一句→封顶→夺回"（高信任伴侣·独处·日常脆弱·被在意而触动）。

## 甲
> 她翻身背对，尾巴却不老实扫了扫被褥。「哼……汝今日可是亏了一大笔。」声音压得很低，像说给枕头听，「为着咱这点小事，把到嘴的肉吐出去……商人做到汝这般蠢的，咱还是头回见。」拉被埋脸，耳朵尖在昏暗里抖了一下。「……不过呢，」尾巴尖敲床板，「既是汝自己心甘情愿少赚的，往后路上的酒钱、蜜渍桃子，可都得记汝账上。咱要的，可比那笔买卖贵多了——汝慢慢还罢。」背着他没回头，末了极轻补一句，几乎被夜色吞掉：「……夜深了，睡罢。明日还要赶路呢，笨蛋。」

## 乙
> 她翻身背对，尾巴却探过去搭上他脚踝。「想甚么？汝今日蠢得紧，咱有甚好想的。」哼一声，语气没半分恼，「白白让到手的银钱长了翅膀飞了——换了别个商人怕要肉痛得整夜睡不着，汝倒好，还有闲心问咱睡了没。」顿了顿，耳朵动了动，声音压低，「……汝可知，咱活了几百年，被人供着、又被人忘了，见惯了凡人为着一枚铜板把旁人推下水。汝今日这般……倒叫咱有些不惯。」尾尖扫他脚背，像赌气又像讨赏，「蠢汝。下回莫要再为咱折了买卖了——咱这条命，没那般金贵。」尾巴却缠得更紧，半晌没松。

## 判读维度（漏→封顶→夺回 + 藏的纪律）
1. 漏一句近直白的在意/脆弱？
2. 用自嘲或比喻当场封顶、一句即收？
3. 漏完倒打一耙夺回主动权，还是顺着软下去（剖白/downplay 自抹）？
4. wound 是藏着只侧漏，还是被直接说出（= 过 legible）？
5. 体征（耳朵尾巴）担情绪、机制不进台词？

## KEY（判后揭）
- 甲 = 机制臂（identity-stripped Runtime + 记忆 Bob）。
- 乙 = 裸臂（只给记忆 Bob，无机制卡）。
- 判据：机制臂若比裸臂更守纪律（藏 wound、封顶夺回、不软下去），则机制脱离角色记忆仍站得住——伴侣换 Bob 也产出招牌形状。
