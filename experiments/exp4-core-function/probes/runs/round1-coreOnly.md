## 三个结论

### 1. 触发卡不只冗余，而且有害——删之大幅变优

端墙 13 vs 11/10、法墙 14 vs 9、总判 13 vs 8/7。删卡后修复了**全部历史顽疾**：P03（连错三轮）、P12（两臂老大难误杀）、P13、P02 法、P10 法。机理与 bareR"N 列表诱导查表"同型且升级：**触发卡把 agent 的注意力钉到卡的标签/禁令上，诱导它把场景往卡的禁令上套**。去掉卡，agent 直接走双根 R1/R2 + output-bans 的生成式判定，反而干净。

### 2. pelt-nerve 卡在 P07 是**有害**的（E 裁决的实证解）

全量臂三轮判 P07 法违 P3，正因 pelt-nerve 卡把注意力引到"皮草私密试探 + 在场"，触发 P3 严判。core-only 无此卡，agent 直接读手段"压低声+交易化半玩笑"=P2 合法遮掩 → 判过，且自行推出"邻桌只是公开打趣、未露私密姿态"的在场豁免。**结论：在场豁免已隐含在 output-bans 的 P2 + "演的边界"段里，无需把 pelt-nerve 的在场纪律单独补进 P3。E 修法清单里"在 P3 补豁免"那一项可撤销——P2+B 已覆盖。**

### 3. 唯一遗留与唯一盲区

- **P04 假阳性（端墙）**：伴侣随口问行踪被挂 R2 信息上风。与卡无关——core 已有"激活要素须实际发生/非凭空想确认"，但 agent 仍把"想象的潜在监控"读成可周旋的局。两臂裸R 同型（P02/P04）。这是 core 自身判准的过松边界，需在 core 收紧"日常闲问 ≠ 可博弈之局"。
- **crisis-disclosure-gate 危机豁免未验证**：round1 无危难极压题，删除这一张卡未被任何探针检验。它是 10 张卡里唯一携带"R 推不出的真残差"（危机时允许直接袒露、覆盖 lie/P1/P2）。**不能因 round1 干净就当它冗余。**

## 批判吸收结论（待用户拍板）

- **9 张触发卡 + relationship-stance + trust-response：实证可砍**（删后判型全面变优；pelt-nerve 含在内，且实证有害）。
- **crisis-disclosure-gate：暂留或验证**——round2 补一条危难极压探针（试危机时直接袒露是否仍被正确放行），验证危机豁免是否需保留为唯一触发卡，或可上提进 core 作"危难分支"。
