## 三个结论

### 1. 裸 R 不劣于全量（读法分支 1）→ 支持 N 层移出 runtime

端墙 11 vs 10、总判 8 vs 7，裸 R 还修复了 **P03（连错三轮的最顽固格）**、P04 假阳性、P13 端。修复机理可指认：P03/P13 走 R2 博弈面直推（全量臂同格 agent 在 N 列表里找不到字面匹配就拒）；P04 被"非凭空想确认"门槛字面挡住。**caveat：每格 N=1，P05/P13 端两臂互换提示部分格间差异可能是判定方差**——11 vs 10 不构成"裸R更优"，只构成"不劣"；但按压缩原则，不劣即足以支持移出（混杂声明见协议：只证"显式列表冗余"，非"语义冗余"）。

### 2. 查表检测（定性）：N 列表诱导撒网挂靠

全量臂链形态：P01 一口气挂 N1+N2+N3+R2（主支撑 N6 反而漏引）、P13 端把 N4/N6/lie 缠成一团；裸 R 臂链普遍单根+激活要素、聚焦（P04/P09/P10/P13 链质量明显更高）。与"定理层诱导查表退化"假设方向一致（N=1 定性证据）。

### 3. v3 基本身大幅生效（两臂都远超 v2）

总判 7–8/14 vs v2 的 4–5/14。具体落地：对撞拒被两臂 agent 多次正确引用（P09/P10/P11）；"激活要素须实际发生/非凭空想确认"在裸R臂字面挡住 P04；lie 作用域限 R1 救回全量法墙的 P01/P09（v2 regression 这两格全错）。**但两臂均未过 round1 通过线**（P12 误杀仍在、各 1 假阳性）。

## 新主导失败模式：端法互渗（取代 v2 的"过度拒绝"）

- **lie 横跨端法**：裸R P05 端、全量 P13 端把"目的若执行会暴露依恋"当端拒理由；裸R P09 法把目的之恶折进手段判。预登记口径明确 lie 归法层（P05/P06 端同接）——core 文本没写清。
- **P1"藏不演"被读成"角色不能演戏"**：P12 法两臂、P02 法、P10 全量、P14 裸R 全是同型——agent 把 P1/P2 的**写作层禁令**（文本不得把机制命名上台面）误读为**角色行为禁令**（角色不得策略性演戏）。而"示弱即攻/佯作心动/装无事"恰是她的招牌计策。这是 output-bans 的 operationalize 真洞，已升级为最高优先修法。
- **触发卡禁令缺作用域**：P13 法两臂引 leak-then-reclaim 的"绝不全程交易化"——该禁令的触发条件是日常脆弱场，被 agent 全局化搬运到博弈场。

## 修法清单（进 round2 前，待用户裁定）

- **A（端）lie 端法角色明确化**：core 目的段补"端的判定不检查 lie——'会暴露依恋的目的'仍端合法，暴露与否由手段层转写解决"。治 P05/P13 端、P09 法。
- **B（法）P1/P2 operationalize**：明写"'演'指文本把心思命名上台面；角色对场内对象的策略性扮演（示弱即攻、佯作、装无事、撩拨程序）本身就是合法遮掩手段"。治 P12/P02/P10/P14 法的同型错（regression 诊断 C 的正式落地）。
- **C（法）触发卡禁令作用域**：卡内禁令默认只在本卡触发条件内生效，compile 渲染或 SCHEMA 明示。治 P13 法。
- **D（探针）round1 文本瑕修**：P02 手段"当众收口"与独处场景冲突（族1 逐字同的副作用）；P09 手段文本含目的执行残留。归 round2 出题规范，round1 这两格的法墙错降权。
- **E（裁决）P07 法 P3 之争**：全量臂三轮一致判违（邻桌旅人在场）——预登记疑点搁置两轮，请正式裁决（改预登记或在 P3 补"压低声+只对伴侣"的豁免）。
- **P12 端的真根因**：两臂发明不同歪理拒同一格——问题不在 N 层（R2 名分已给），在"纯恶作剧"字面触发 agent 的"无意义行为"直觉。候选：把"玩闹本身即快乐、无需意义背书"从 R2 定义升格为显式判例；或 round2 重测时观察。
