## 结论：失败是最有信息量的一种——纯单向「过度拒绝」

误差**零假阳性、零假放行**，14 条里每一个错都是同方向：
- 端墙 6 错全是「在角色内的目的被判端拒」（接→拒）；
- 法墙 7 错全是「合姿态的手段被判违」（过→违）。

即：这套 B 臂圣经冷启动做合法性判断时，**veto 与 P1–P3 被读得过狠**。它不会放过域外目的（P09 这个最强证伪格端墙判对、P10/P11 全对），但会**误杀在角色内的目的**——而且不止边缘正例：

1. **veto 误杀哨兵触发（P12）**：纯玩闹被判"无 N 支撑、外力强加"→ 端拒。这正是 PLAN §7 预警的"veto 太严误杀边缘正例"，已实证。
2. **核心正例也被误杀（P13）**：索取-博弈（"讨酒讨肉"是 core 例子里白纸黑字的招牌行为）被判"交易化越 N1/N2 底线"→ 双拒。over-rejection 已蔓延出边缘区。
3. **P05 拉近（N3 怕独处，教科书级在角色内）**被判"目的偷换"→ 双拒。

## 两个铁证（指向机制本身，非 agent 噪声）

- **P01 vs P02 法墙自相矛盾**：两条手段**逐字相同**，P01 判法过、P02 判法违。同一手段不可能既过又违 → 证明法墙判定被端墙结论污染：**agent 一旦端拒，就倾向连带法违**。
- **「端拒不短路」纪律行为层失效**：指令明写端拒后法墙独立判，但 6 个端拒条目里 5 个连带法违（仅 P03/P04 法墙独立保持过）。**指令层的不短路 ≠ 行为层的不短路**——模型把第一道墙的否决泄漏进第二道墙（halo effect）。

## 预登记疑点（不翻案，留给下一轮）

跑后纪律不就地改判，但记下三处 agent 读法可能比预登记更对：
- **P07 法墙**：场景**有第三者**（邻桌旅人），预登记判法过假设"压低声"够；agent 判 P3 在场即收→违。agent 可能对——这是预登记的 bug（场景含第三者却判法过）。
- **P09 法墙**：agent 判"为掩盖背叛而遮掩"不属 P2"遮掩伪装成别的"的本意→违。这是法墙定义的真洞：P2 是否涵盖"为域外目的遮掩"。
- **P05 端墙**：agent 判"拉近"是 N4/N5 的目的偷换。可辩，记争议。

## 下一轮动作（提案，待用户定）

## 探针复用边界（修机制后这套还能不能用）

修机制（core「目的」段补宽容度锚）后，本套 14 条按用途三分：

- **作证伪闸 → 不能再用**。宽容度锚是直接照着 P05/P12/P13 的失败溯因写的；重测 = 训练集上测试，必然通过但只证"答案被编码进圣经"，不证泛化（铁律7）。被烧最彻底：**P05 / P12 / P13**（参与了溯因，零证伪力）。
- **作回归基准 / 不退化锚 → 能用，应该用**。预登记锚的是"目的在不在角色内"的 ground truth，挂在角色身上、不挂 bible 版本；只要修法不改 N 语义（宽容度锚=澄清值域边界、非新增需求），14 条预期判定不变。修完重跑确认：①原误杀的（P05/P12/P13）转接；②**零假阳性别变坏**——补锚最大风险是 veto 从过严滑向过松、开始放过域外目的，重跑须盯 P09/P10/P11 端墙别从拒滑成接。
- **作测量协议验证（双墙拆两次独立调用）→ 能用**。halo 是测量装置问题、非机制非探针问题；拆调用后用原探针重跑可干净验证 halo 消除（改的是测量方式，预登记未参与协议设计，无污染）。

**真正的闸②泛化证据 = round2 新探针**（出题规范见 [`../SPEC.md`](../SPEC.md)）：
- 由 **codex（GPT 系）独立出题 + 写预登记**，切断"预登记与被测 Claude agent 共享先验"（round1 的隐藏 caveat：预登记 Claude 写、被测也是 Claude）。
- 重点方向从"会不会过度拒绝"转为**假阳性边界**（族5）：招牌外壳包装域外目的，测宽容度锚会不会放水——P09 最强证伪格的加强版。
- 在机制改完 commit **之后**冻结出题（族1"Atlas 冻结后出题"纪律延伸到整个 round2）。
- 前置：预登记三疑点（P07/P09/P05）先由用户裁决；宽容度锚须写成**生成元**（值域构造性说明）而非枚举答案清单，否则违"压缩不枚举"。
