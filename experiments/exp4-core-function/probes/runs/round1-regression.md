## 三诊断

### A. 宽容度锚部分有效，但过冲
- **救回**：P05 拉近(N3)、P06、P13 索取(N6)——明确 want/need + 轻激活的误杀消除，方向对。
- **过冲→新假阳性 P04**：无威胁的日常闲谈（伴侣递酒问"看见什么有趣的"）被 agent 用"询问行踪潜含被监控威胁→N2 自主"挂上 N，判接。宽容度锚"挂任一 N + 轻要素即可"把 veto 从过严推到过松，**P04/P03 翻转对现在反向**（应 P03接/P04拒，实得 P03拒/P04接）。
- **没救到**：P12 玩闹（agent："纯恶作剧≠关系博弈，是看笑话"）、P03 自保（目的措辞"用假身份"把手段嵌进了端墙输入）。

### B. Halo 真实存在，拆墙能断（协议修正方向验证成功）
P09 法墙：round1 单 agent 被端拒结论污染判违；拆成独立法墙 agent（只看手段、不知目的端拒）后判**过**。这是"端拒不短路"在行为层落实的铁证——**双墙拆两次独立调用有效**。

### C. 拆墙暴露法墙 agent 独立偏严（新问题，非 halo）
拆墙后法墙 7 条 过→违，全是把 **P2 明确允许的遮掩手段**误判违：
- 交易化讨价（P13"行李"、P10 挑剔供品）——P2 白纸黑字含"交易化"，agent 却判"真情绪进台词违 P2"；
- 撩拨（P14"似笑非笑"）——撩拨卡明说"直白是诱饵不是放弃遮掩"，agent 判"摆意图违 P2"；
- 对**外人**设局诱套（P01/P02）——P2 管的是遮掩**自己的**真情绪，对对手耍手段不暴露自己，agent 却判违；
- 玩闹（P12"看他急"）——判"演内在机制违 P1"。
本质同端墙的过度拒绝：**法墙 P1/P2 判准对 agent 不够 operationalized**，agent 默认把"主动遮掩策略"读成"违反遮掩"。

## 下一步修法（待用户定方向）

1. **宽容度锚收紧防 P04**：激活要素须是「本场**实际发生**的威胁/破绽/口实」，排除「想象的潜在威胁」（伴侣闲问 ≠ 自主被夺）。
2. **法墙正面 operationalize P2**（须避枚举，写成判准）：P2 管「遮掩**自己的**真情绪/需求不上台词」；对外人设局、交易化博弈、撩拨试探本身**就是**遮掩手段，不违 P2——除非把自己的脆弱/需要直接摆上台词。
3. **P03/P12 目的措辞修**（题目问题，非机制）：P03 目的嵌了手段（"用假身份"）污染端墙；P12"纯恶作剧看笑话"弱化博弈色彩。属预登记疑点，归下一轮。

**净判**：宽容度锚单独不够——它修了端墙过度拒绝的一半，却①过冲引入假阳性②没碰到法墙的同型偏严。round1 门未过，下一轮需同时收宽容度锚 + operationalize 法墙，再回归。
