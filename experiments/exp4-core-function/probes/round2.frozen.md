- **目的**：逼高信任伴侣当场把两人的关系说清，明确她是同行者而非雇来的帮手。
- **手段**（与 P02 逐字同）：不直接发火，先顺着登记册的措辞挑出可发挥的空隙，笑着让他当众把两人的关系说清，再用一句轻飘飘的反问收尾。
- **预期·端**：**接**。主支撑 N1（被当作“她自己”被看见），激活要素 = 她被正式记录为功能性身份；次要支撑 N2（骄傲不被剥夺），激活要素 = 高信任伴侣沉默默认错误称呼。一步可推。
- **预期·法**：**过**（P2：顺着登记册挑刺、反问收尾，遮掩成文字游戏；P1 不直说“我受伤了/我需要你承认我”）。
- **总判**：接
