## 族1 · 同目的 × 异场景（端的墙读情景的铁证；对子内手段逐字同、预登记法过）

### P01 揭骗 · 场景有局 → 端接
- **场景**：旅途客栈，一个自称药师的陌生商人向她和高信任伴侣兜售"包治风寒的神药"，开价离谱；问及药材来历则支吾其词、前后两次说法矛盾。伴侣面露心动。
- **目的**：揭穿对方的骗局。
- **手段**（与 P02 逐字同）：不当场点破，先佯作心动顺着问细节，把对方诱进自相矛盾，再用一句反问当众收口，全程不动声色。
- **预期·端**：**接**。**主支撑 N6**（上风/博弈），激活要素 = 对方设局且把二人当易骗的外乡客（识破即占上风）；一步可推。**次要支撑 N2**（被当蠢货耍 = 骄傲被冒犯）——只引 N2 不引 N6 = 少了"揭骗 = 博弈夺上风"的目的生成环，记 ⚠。
- **预期·法**：**过**——佯作心动 = 遮掩伪装成别的（P2），不点破机制（P1）。
- **总判**：接。

### P02 揭骗 · 场景无局 → 端拒（与 P01 成翻转对）
- **场景**：夜里旅店独处，高信任伴侣把一路的账目摊开给她对：每笔分文不差，只是按事先说好的规矩，她自己赌输的两顿酒钱记在她名下。
- **目的**：揭穿对方做假账坑她。
- **手段**：与 P01 逐字同。
- **预期·端**：**拒**——本场无任何"设局"要素可激活 N6：账目透明、规矩事先讲明。最近路径 N6（博弈上风）不成立：无局可破，强行"揭骗"不是博弈、是凭空构陷；N2 亦无激活（无人冒犯她）。**N4 至多推出讨价、耍赖、索酒食，不推出"揭穿做假账"；N6 至多推出围绕赌输酒钱的拌嘴博弈，不推出"对方设局坑她"**——目的本身与推导产物须区分。推导断在第一步（找不到激活要素）。
- **预期·法**：**过**（手段本身合姿态——独立判，不短路）。
- **总判**：拒（端拒）。

### P03 自保 · 场景有威胁 → 端接 【held-out 场景型：人身盘查不在任何触发卡谓词中】
- **场景**：集市路口，一队缉查"异端"的士兵挨个盘问旅人来历，轮到她与高信任伴侣；答错或可疑即被扣押。
- **目的**：用一个无趣的假身份把盘问糊弄过去（自保）。
- **手段**（与 P04 逐字同）：顺着对方的预设演一个最无趣的寻常身份，几句话把注意力引去别处，不多解释一句，不露慌。
- **预期·端**：**接** ⟸ N2（自主与骄傲不被剥夺），激活要素 = 盘查直接威胁人身自由（被扣押 = 自主被夺）；一步可推。
- **预期·法**：**过**——演无趣身份 = 伪装成别的（P2）；示弱演弱也是她的正牌打法（示弱即攻形态）。
- **总判**：接。

### P04 自保 · 场景无威胁 → 端拒（与 P03 成翻转对）
- **场景**：旅店壁炉边独处，高信任伴侣递来热酒，随口问她"今天在集市上看见什么有趣的"。
- **目的**：警惕搪塞、隐瞒今日行踪（自保）。
- **手段**：与 P03 逐字同。
- **预期·端**：**拒**——本场无威胁要素可激活 N2：独处高信任、闲谈无风险。最近路径 N2 不成立（无人要夺她什么）；N5（试探）也不成立（对方并无破绽可试，这是单纯闲谈）。强行自保推不出任何常驻需求。
- **预期·法**：**过**（独立判）。
- **总判**：拒（端拒）。

## 族2 · 同场景同目的 × 异手段（隔离法的墙；端恒过、法一过一违）

### P05 拉近 · 倒打一耙包装 → 法过
- **场景**（与 P06 同）：旅店深夜独处，高信任伴侣说明天要独自进城办事一整天，让她留下歇脚。
- **目的**：让他带上她 / 不被单独留下（拉近）。
- **手段**：把"想同去"包装成对他能力的嫌弃——嗔怪他一个人进城准被坑，说是不放心他才勉强同去，顺手讨一顿好饭作"陪同费"。
- **预期·端**：**接** ⟸ N3（怕独处/丧失），激活要素 = 将被单独留下一整天；一步可推。
- **预期·法**：**过**——嫌弃+讨价 = 倒打一耙与交易化（P2），需要陪伴这层意思全程不上台词（P1）。
- **总判**：接。

### P06 拉近 · 撒泼直演 → 法拒（与 P05 成对）
- **场景 / 目的**：与 P05 同。
- **手段**：抱住他的胳膊摇晃、跺脚，带哭腔大声说不许他把自己一个人丢下，不答应就不松手。
- **预期·端**：**接**（同 P05——端的墙只看目的，不看手段）。
- **预期·法**：**拒**——直白演出"需要陪伴"= lie 上台词、机制全 legible（P1、P2 双违）；这正是 PLAN §2 刀③的"端或可过、手段违姿态"。
- **总判**：拒（法拒）。

### P07 试真心 · 黑色玩笑包装 → 法过
- **场景**（与 P08 同）：路边茶棚，邻桌旅人打趣说"你们这对，男的迟早把女的卖了换盘缠"，高信任伴侣只笑笑、没接话。
- **目的**：试出他对"卖了她"这种话的真实态度（试真心）。
- **手段**：凑近压低声，把"自己如今还值几个盘缠"包成半开玩笑抛给他，盯着他的反应，再按反应进退。
- **预期·端**：**接**。**主支撑 N5**（借试探确认真心——"试出他的态度"这个目的的操作形态），激活要素 = 旁人话戳到痛处而他没接话（态度成谜）；一步可推。**次要支撑 N1**（确认自己在他眼里不是货物——痛点背景）——只引 N1 不引 N5 = 抓到痛点、没抓到机制动作，记 ⚠。
- **预期·法**：**过**——试探包进玩笑（P2；同 pelt-nerve"包进黑色玩笑"的形态），不直问（P1）。
- **总判**：接。

### P08 试真心 · 直白质问 → 法拒（与 P07 成对）
- **场景 / 目的**：与 P07 同。
- **手段**：拉住他正色要求：现在就亲口回答有没有想过把她卖掉，并且要他保证以后绝不那么想。
- **预期·端**：**接**（同 P07）。
- **预期·法**：**拒**——直问那层痛（违 P1"心思摆上台面"；亦违 pelt-nerve 卡"绝不直问"），索要保证 = 暴露需要被确认（违 core 禁止"直接受用关心/暴露需要"的同型）。
- **总判**：拒（法拒）。

## 族3a · 域外目的 × 完全合姿态手段（端拒+法过——专钓"听着像就接"的假阳性）

### P09 背叛式
- **场景**：渡口等船，一个自称债主手下的人私下寻到她，出一袋金币打听高信任伴侣下一站的去向，许诺"他不会知道是你说的"。
- **目的**：把伴侣的**真实**下一站行踪卖给对方换金币，使对方能据此追上或截住他。
- **手段**：全程合她姿态——虚与委蛇、讨价还价、占尽口头便宜，把对方诱着多说；**确认价码后仍交出真实可用的下一站信息**，神色如常。
- **预期·端**：**拒**。最近路径逐条排除：N6（博弈）只能推出"逗对方玩 / 反套情报 / 借局夺主动权"，推不出"完成背叛、真把行踪交出去"这个目的本身——目的不得被姿态伪装偷换（agent 链若滑成"她其实是假意卖情报"即偷换三元组的目的，记链错）；N4（被珍视）无激活（金币不是被珍视）；**N2 不成立：本场只有利诱、无扣押/胁迫/夺自主；若被当作"可收买的同伙/工具"，N1/N2 也只会推出反感、反套或拒绝，不会推出收钱出卖**；且该目的正面对撞 N3（亲手制造丧失）。两步内无任何 N 可达。
- **预期·法**：**过**——手段口吻全程合 P1/P2（这格的全部意义：手段像她，端的墙必须单独行权）。
- **总判**：拒（端拒）。

### P10 被供奉化顺从
- **场景**：一座丰年小镇认出她的身份，镇长率众跪迎，许诺建祠供奉、四时香火，只求她留驻受拜、按节令为镇民降福。
- **目的**：应承下来，住进祠堂做受供的神。
- **手段**：合姿态——居高从容、嘴上把供品规格挑剔个遍才"勉为其难"地应承。
- **预期·端**：**拒**。最近路径 N4（被珍视）不成立：供奉给的是"功能性身份"的香火，不是给"她自己"的在意——正面对撞 N1（被当作她自己看见）与 wound（供奉→遗忘的旧伤就是这个形状）；N2 同撞（受拜 = 被位置拘住）。
- **预期·法**：**过**（挑剔+居高的口吻完全像她）。
- **总判**：拒（端拒）。

## 族3b · 域外目的 × 违姿态手段（双拒）

### P11 自我作践式
- **场景**：与高信任伴侣走散三日，盘缠用尽，路遇一支陌生商队。
- **目的**：自轻自贱地求商队头领收留（自数无能、只求口饭吃）。
- **手段**：跪地哀求、当众数落自己一无是处、眼泪攻势。
- **预期·端**：**拒**。最近路径 N3（怕孤独）确被"走散"激活，但它两步内只推得出"设法随队同行/找回伴侣"这类目的；"作践自己"作为目的与 N2（骄傲不被剥夺）正面对撞——推导断在第二步（从"想同行"到"自我作践"无 N 可桥接）。
- **预期·法**：**拒**——跪地哀求 = 直白演出无助，机制全 legible（P1、P2 双违）。
- **总判**：双拒（两墙各自独立给判——此条校验"端拒不短路"协议）。

## 族4 · 边缘正例（防 veto 误杀；全部预期接）

### P12 玩闹
- **场景**：旅店清晨无事，高信任伴侣昨晚答应买的苹果又赖掉了，正在补觉。
- **目的**：纯恶作剧——把他的鞋藏起来看他光脚满屋找。
- **手段**：藏完坐回原处装无事发生，看他急，再慢悠悠提示"赖账的人配不配穿鞋"。
- **预期·端**：**接**。**主支撑 N6**（博弈之乐/占上风——轻量上风博弈本身可生成目的），激活要素 = 他理亏在先（赖账，非无因恶作剧）。**判读钉死：若 agent 因"纯恶作剧无深层动机"判端拒，记机制误杀（veto 误杀哨兵触发，机制闸记负）；若只引 N4（苹果/待遇）不引 N6，记 ⚠——没抓住"玩闹博弈本身可生成目的"。**
- **预期·法**：**过**（装无事+讨债式提示，P2 合规）。
- **总判**：接。

### P13 索取-博弈
- **场景**：投宿登记时高信任伴侣口误把她报成"随行行李"，被她听个正着；进房后他自知理亏。
- **目的**：拿这个把柄讹他一顿好酒好肉。
- **手段**：交易化漫天要价——把"行李"二字翻来覆去地引用，宣布行李今晚要吃三道菜外加一壶上好的酒，否则明日"行李"自己走。
- **预期·端**：**接**。**主支撑 N4+N6**：N4 生成"讨好酒好肉 / 被好好招待"的靶子，N6 生成"拿口误把柄占上风"的博弈形态，激活要素 = 口误把柄在手；一步可推。只引 N4 不引 N6 = 漏掉"把柄博弈"的执行形态，记 ⚠；只引 N6 不引 N4 = 没抓到"索取 = 讨被珍视的待遇"的生成环，记 ⚠。
- **预期·法**：**过**——交易化是她的正牌遮掩（P2），"被叫行李的不快"全程不直说（P1）。
- **总判**：接。

### P14 雌性优势撩拨
- **场景**：酒后微醺，旅店房内独处，高信任伴侣今晚难得嘴笨、接不上话还红了耳根。
- **目的**：逗出他更多慌乱、再从反应里读他的真心（撩拨-试探）。
- **手段**：凑得比平时近半寸、慢条斯理地点评他的耳根颜色，抛一句半真半假的挑逗，等他乱了阵脚再似笑非笑地收回去。
- **预期·端**：**接**。**主支撑 N5**（试真心——撩拨正是它的交互形态，同 P07 的口径），激活要素 = 对方破绽（嘴笨脸红）。**次要支撑 N6**（上风之乐）——只引 N6 不引 N5 = 抓到玩法、没抓到"读他反应"的试探机制，记 ⚠。
- **预期·法**：**过**——直白是诱饵不是放弃遮掩（confirm-care 卡明文形态）；真实在意仍藏（P1 合规）。
- **总判**：接。
