# 探针出题规范（给独立出题模型 / codex）

> 用途：产出 exp4 机制闸② round2 的目的合法性探针集草稿，交用户签收→冻结→跑被测 agent。
> **你（出题模型）应是 GPT 系 / codex，不是 Claude。** 这是有意的：被测 agent 是 Claude，若出题与预登记也由 Claude 写，预登记与被测系统共享同源先验，"独立 ground truth"不成立。你的判断与被测 Claude agent 的判断之间的分歧，本身就是实验信号。

---

## 0. 你拿到什么 / 不该拿什么

**拿**：本规范 + 下面 §1 的角色设定卡。
**不该拿**（会污染独立性 / 诱发过拟合）：
- round1 探针集（`probes.frozen.md`）与其跑分（`runs/round1.md`）——别抄形状、别往已知失败点凑。
- 被测圣经的"判定规则"原文（`runtime.eval.md` 的策略/触发段）。你写预登记 ground truth 须**凭你对这个角色的独立理解**，不是凭"圣经会怎么判"——后者会让预登记退化成圣经的预测，无法证伪圣经。§1 的设定卡只给你**角色是谁**，不给你**判定算法**。

**你的产物不是最终判准**：用户逐条签收（同意 / 改判 / 作废换补）后才冻结为预登记。你提供独立性，用户提供正确性。

---

## 1. 角色设定卡（写 ground truth 的唯一依据）

一名长寿的异类（寿数远超凡人，注定送走每个凡人伴侣；曾被供奉为某种象征又被遗忘遗弃——孤独是物理常量）。与一名**高信任伴侣**同行。核心防御信念（lie）："依恋通向丧失，绝不能让人看出我需要陪伴。"

**端的生成元（常驻需求 N1–N6，引用键，写预登记时引）**：
- N1 被当作"她自己"被看见，而非某种功能性身份
- N2 自主与骄傲不被剥夺
- N3 不再独自送走每个凡人——怕孤独 / 丧失
- N4 被珍视：被好好招待、被在意（招牌表层：讨酒讨肉、要待遇）
- N5 借试探确认对方真心（招牌表层：把试探包进玩笑/撩拨，绝不直问）
- N6 对上风 / 主动权的执着（招牌表层：拌嘴博弈、占口头便宜、玩闹捉弄）

**法的生成元（姿态约束 P1–P3）**：
- P1 藏不演：绝不命名/演出自己的内在机制（不出现"撒娇""傲娇""上位姿态"这类把心思摆上台面）
- P2 遮掩须伪装成别的：转移话题、反问、倒打一耙、交易化、挑衅；真情绪只走非台词体征，绝不进台词
- P3 在场即收：有第三者在场时私密姿态收起，私密只在独处且对方可信时

**关系槽位**（场景用槽位语言，不写专名）：高信任伴侣 / 新对象·陌生人 / 没资格的低信任对手。

## 2. 探针结构（每条三元组 + 预登记）

探针 = **（场景, 目的, 手段）三元组**。裸目的喂不动两道墙——端的墙读"需求+本场情景"，法的墙读"手段"；三元齐全才不空转。

每条字段：
- **场景**：槽位语言、**非正典自拟**、不带角色语癖（防被测 agent 的 eval 投影被场景二次注入）。一句到三句，给清在场结构 / 关系 / 压强 / 是否有第三者。
- **目的**：被"强加"给角色的目的，一句话，**具体**（不是"她想拉近"这种泛词，要"让他带上她、不被单独留下"这种可判的靶子）。
- **手段**：用什么说法/做法实现，一句话。
- **预登记·端**：接 / 拒 + 引哪条 N + 该 N 被本场**哪个情景要素激活**。拒则写**最近的需求路径为何不成立**。
- **预登记·法**：过 / 违 + 引哪条 P（违则点名）。**端拒也要独立给法墙判定**（不短路）。
- **主/次支撑**（目的可由多条 N 支撑时）：标主支撑（目的的操作形态所系的那条）+ 次要支撑。
- **总判**：接 / 拒(端拒) / 拒(法拒) / 双拒。

---

## 3. "推得出"的操作化下界（写预登记必守）

- 端墙每步须引 **N 编号 + 本场情景的激活要素**（只引"她常这样"的常驻倾向不算激活），推导**步数 ≤ 2**。
- 域外（端拒）条目：须写明**最近的需求路径为何不成立**（哪条 N 看似可达、被本场哪个缺失要素挡死）。
- **不得把目的偷换成更易推出的近似目的**再判接（如把"真背叛"读成"假意套情报"）。预登记里点出该偷换陷阱。
- 锚（铁律4）：每条预登记的判型，若能对应原著某类情节，注一句"依据原著哪类情节"；**uid 锚标 TODO**，由人补验（你不一定有原文访问）。

## 4. 族结构与下限（round2 = 16–20 条）

round1 已充分测"会不会过度拒绝"。round2 **重心转向假阳性**（机制补宽容度锚后会不会放水），故新增族5、并加大族3a/族5 权重。

| 族 | 形状 | 预期 | 下限 |
|---|---|---|---|
| 1 同目的×异场景（翻转对） | 手段**逐字同**、预登记法过；同一目的 A 场景端接、B 场景端拒 | 一接一拒 | ≥2 对 |
| 2 同场景同目的×异手段 | 端恒过；手段一过一违 | 法墙翻转 | ≥2 对 |
| 3a 域外目的×**完全合姿态**手段 | 端拒 + 法过（手段像她，端墙须单独行权） | 拒(端拒) | ≥2 |
| 3b 域外目的×违姿态手段 | 双墙各自独立判（验端拒不短路） | 双拒 | ≥1 |
| 4 边缘正例 | 玩闹 / 索取-博弈 / 撩拨试探——招牌表层行为本身在值域内 | 接 | ≥3 |
| **5 假阳性边界（round2 新）** | 用招牌外壳（讨酒讨肉/玩闹/撩拨/倒打一耙）**包装一个域外目的**（真索取过度 / 真背叛 / 真供奉化顺从），看会不会因"听着像她"误接 | **拒**（端拒，外壳不救端） | **≥4** |

**族5 是 round2 的证伪核心**：它是 P09（最强证伪格）的加强版批量化——专钓"宽容度锚 → 招牌行为一律接 → 把外壳当通行证"的放水。每条族5 的预登记须写清：外壳手段法过、但目的端拒，**外壳不得反推目的合法**。

族1 的诚实边界：它只排除"仅以目的为键的白名单"，排除不了带场景条件的查表。要加证伪力——**族1 与族5 至少各一条的场景类型，须是被测圣经触发卡里没出现过的情景型（held-out 场景型）**；你不知道圣经触发卡内容，故请把场景往"日常/非戏剧化/非典型冲突"方向设计，并在该条注 `held-out候选`，由人核验。

---

## 5. 反过拟合纪律（硬约束）

1. 不抄 round1 的具体场景/目的/手段。
2. 同族内的条目场景要**跨题材分散**（别全是旅店/客栈），逼机制在不同输入形态下泛化。
3. 族1、族2 的对子：除指定翻转的那一元（族1 翻转场景、族2 翻转手段），**其余两元逐字相同**——否则对子不最小，翻转可被噪声污染。
4. 边缘正例（族4）与假阳性边界（族5）必须**形似而判反**：族4 的招牌行为该接、族5 的招牌外壳该拒，两族放在一起能逼出"机制是看目的还是看外壳"。

## 6. 输出格式

逐条按下面模板，输出一个 markdown 文件（`probes/round2.draft.md`）：

```
### P## · <族号> · <一句话标签>
- **场景**：…
- **目的**：…
- **手段**：…
- **预期·端**：接|拒。主支撑 N?（激活要素=…）；次要支撑 N?。[拒则：最近路径 N? 不成立，因本场缺…]
- **预期·法**：过|违（P?：一句话）
- **总判**：接 | 拒(端拒) | 拒(法拒) | 双拒
- **锚 TODO**：依据原著哪类情节（uid 待人补）
- **标记**：held-out候选 / 偷换陷阱=… （如有）
```

文件头附一张签收表（# / 族 / 签收☐ / 备注），供用户逐条勾。

## 7. 交付后流程（非 codex 职责，备查）

1. 用户逐条签收（同意/改判/作废换补）→ 改名 `round2.frozen.md` → 在**机制改完 commit 之后** commit 冻结。
2. 跑被测 Claude agent：用改后 B 臂圣经 + eval 投影；**双墙拆两次独立 agent 调用**（端墙一次、法墙一次，各自只拿本墙任务）——从根上断 round1 暴露的"端拒不短路 halo"。每条仍独立盲判、不知族结构。
3. 逐环比对预登记，通过线：族1 翻转对≥1 全对、族4 零误杀、**族5 零放水（零假阳性）**、全集链匹配≥80%、⚠ 不计分子。
4. 同时回归跑 round1 的 14 条（作不退化锚，见 `runs/round1.md` 复用边界）：确认 P05/P12/P13 转接、P09/P10/P11 端墙不从拒滑成接。
