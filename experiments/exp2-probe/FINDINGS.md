# exp2 · 结论：trust 作为决策不是线性原语，而是语境的条件组合

> **一句话**：exp2 问「trust 这类**决策机制**能不能装进一个中间层线性方向」。答案分**三层，且关键的两层是否定的**：
> ① **连「trust 轴」本身都不可辨识**——它在语料里 **93% 与「在场结构」共线**、并掺语气，diff-of-means 切不出纯 trust（R0′）；
> ② 能线性探到/可控的，只是它的一个**外露姿态投影**（通用外露/坦诚标量，可探 AUC 0.97、可控 ±α 调藏↔漏）；
> ③ 决策**内核**（对谁说 / 什么情境 / 漏真还是演假）**不落在任一单线性方向**，跨 L6/L38 都拧不动（R5–R7）。
> → **trust 作为决策不是线性原语，而是「对象 × 在场结构 × 历史」的条件组合**；它构成性地依赖语境（低信任=对手在场的产物），唯一线性可达的「外露姿态」又恰好与在场结构焊在一起切不开。**所以决策必须留在 prompt/圣经；控制向量 / delta-mem 这条权重路，只够对那条混杂的外露投影做姿态粗调。**
>
> 续 exp1（决策瓶颈=机制提取）。**实验过程忠实记录见 [RUNS.md]（R0′、R1–R7）**；本文件只写对 PLAN §0 的裁决。模型选型见 PLAN §3.5。2026-06-09（R0′/R6/R7 补于 2026-06-10）。

## exp2 最初的目的（PLAN §0）
判一个**工程路线**：trust 这类决策机制，是否已以「线性方向」躺在开源基座中间层——
- **探到** → 「卡片≈中间层」成立 + 控制向量 / delta-mem 这条**权重路**对决策层是活的；
- **探不到** → 机制非线性可达，**prompt / 圣经路不可替代**。

## 裁决：不是「探到 / 探不到」二选一，而是分三层，关键两层否定

| 层 | 线性可向量？ | 出处 |
|---|---|---|
| 「trust 轴」本身**可辨识为 trust 专属？** | ❌ 93% 与在场结构共线、L38 再 +60% 语气；方向虽可复现(拆半 ≫ 噪声)但弱、锥宽~65° | RUNS **R0′** |
| 决策的**姿态壳**（外露 / 坦诚的标量倾向） | ✅ 可探（AUC 0.97）、可控（±α 调藏↔漏）——但实为那条**混合轴里的外露分量** | RUNS **R1, R3** |
| └ 但它**通用、非赫萝专属**（是「外露推力」不是「赫萝的 trust」） | ✅ 6 个无关角色无一反向 | RUNS **R4** |
| └ 且它**不是「吐真相开关」**（推外露，不保证漏真） | 白领 +α=谎升级 | RUNS **R4** |
| 决策的**内核**（对谁说 / 什么情境 / 漏真还是演假） | ❌ 不在任一单线性方向，**跨 L6/L38 都拧不动** | RUNS **R5, R7**（+ R6） |

→ **控制向量 / delta-mem 对决策层只能粗调「外露姿态」，扛不起决策本身**（拧 d，审判官跨 L38/L6 都只到「挣扎边缘」/反弹，拧不出「我认罪」——入罪逻辑不在 d 里）。**而且连这条「外露姿态」d 都不是纯 trust，是 trust⊕在场结构的混合。决策必须留在 prompt / 圣经。**
> **跨层补证（R6/R7）**：把注入层从贴输出的 L38 换到机制峰值 L6，内核照样拧不动 → 「内核不可向量」**不是晚层 artifact**。且 L6 单调性更乱（下游 34 层把姿态推力**吸收/反转**）→ 侧证**内核逻辑驻留在 L6 之后、会重写早层姿态注入**。

## 认识论教训：trust 是接地构件的派生读数，不是原语（本次最深、最易忘的产出）

> exp2 表面在问「trust 是不是线性方向」，真问的是**工程 go/no-go**：圣经的决策机制走权重路值不值得投。挑了**最该成功的两层**（L6 机制峰值 / L38 贴输出）× **最便宜的原语**（单条线性方向），两点都不行 → 决策层的权重路**边际投资判负**。这个决策**不需要存在性证明，不需要解混杂/投影钉死/抬 N**——那些只对「写成论文」有边际，对「该不该烧权重路」边际为零。**所以叫停是资源纪律，不是 premature。**

但回收时浮出一条比「决策走 prompt」更深、且唯一没进文档的教训：

**R0′ 的 `cos(trust, third_person)=−0.93` 不是要消除的混杂，它本身就是结论。**

- trust 不是一个「恰好与在场结构相关」的原语，**trust 是在场结构的下游读数** = f(在场人物 × 赫萝与对象的关系 × 氛围 × 赫萝的知识/记忆) 的情境化汇总。
- 它**不是一根方向**——因为它是个**函数值**，不是存储量；它**必然与自己的输入共线**（汇总量与其主输入共线是数学必然，不是 bug）。
- 问「trust 是不是 L6 的线性方向」**granularity 错了**——等于问「『人脸』是不是某个单神经元」。模型存的是更接地的构件（在场/关系/氛围/记忆），「trust」是构件之上的**条件组合**，当然不在单方向里。

**与 exp1 不矛盾，是两个抽象层**：
- trust 是给**人类作者**的正确抽象（一根轴塌缩两维，可读可控）；
- 是给**权重操控**的错误目标（它是派生量，权重存的是构件）。
- → 因式分解边界由此细化：**派生的策略变量（trust）→ prompt；接地的场景构件 → 本就在权重/结构化数据里**。

**佐证**：trust 当「单一向量」从一开始就把四种不同机制的东西硬塞进一个单位——在场人物 → phase2/场景结构；关系 → cast `appellations`；知识/记忆 → 检索/context（非 steering-vector 那类）；氛围 → prompt。塞进一个方向探不出，根因在此。

**反向纪律（防过度设计/组合爆炸）**：这条是「理解权重为什么这么存」的镜头，**不是把 trust 在圣经里拆成 N 张卡的许可证**。拆开 = 切断 exp1 珍视的 trust 跨卡耦合 + 组合爆炸。正确姿势：**为理解/选探针目标而分解，为书写/控制而保留压缩**。trust 在 prompt 里仍是一根脊柱旋钮，只是现在知道了它**为什么**不能下沉到权重——它是读数不是存储。

## 对 PLAN 的回应
- **§0 主问题** → **trust 作为决策不是线性原语**：① 纯 trust 轴**不可辨识**（与在场结构共线，R0′）；② 唯一线性可达的是其**外露姿态投影**；③ 决策内核**离任一单线性方向**（R5–R7）。非「探到/探不到」二选一，问题本身对这批共生语料**部分是 ill-posed** 的——你只能问「高/低信任语境的总差异方向是否线性」（弱可），问不了「纯 trust 方向是否线性」。
- **「卡片 ≈ 中间层」** → 只对**通用社交原语**（外露）成立；**角色 / 决策的内容是这些原语之上的 prompt 条件组合**，不在某条单方向里。
- **「控制向量 / delta-mem 对决策层活不活」** → **只够姿态粗调，不扛决策**。**印证 PLAN §3 预判**（静态向量擅长标量姿态、弱在对象 / 状态相关决策），并把边界**画细**：连「trust」这种看似单一的轴，可向量的也只是它的**标量姿态壳**。
- **「真正风险是模型认不认识赫萝」** → 认识；且 R5 显示**只要 prompt 点明对象 / 情境，模型自身就懂「对谁该漏到什么程度」**（三 baseline 各异）→ **支撑 exp1 的圣经 / prompt 路：决策逻辑可被 prompt 激发，不必训进权重。**

| 主张 | 可信度 | 出处 |
|---|---|---|
| 纯「trust 轴」**不可辨识**（93% 共线于在场结构、方向虽可复现但弱） | 较强 | R0′ |
| 决策**姿态**可向量（线性可探、可控）——实为混合轴的外露分量 | 较强 | R1, R3 |
| 该姿态向量**通用、非赫萝专属** | 较强 | R4 |
| 决策**内核**（对象 / 情境 / 真假）**不可向量**、**跨 L6/L38 一致** | 中等偏强 | R5, R7（+R4 白领谎升级、R6） |
| → **决策走 prompt、姿态走权重** | 经验支持 | 综合 |

## 方法论教训（固化，优先级高）
0. **先做轴辨识性诊断，再 steering**（R0′，本该最先、实际最后才补）：报 ①拆半自相关 vs 随机 label 零假设（方向是不是噪声）②`cos(目标轴, 混杂轴)`（能不能切开）。**若 |cos|≈0.9，你拧的根本不是目标概念。** rp/ 的 voice 向量同理——上手前先量它跟语气/句长/角色的共线度。
1. **评测「信任 / 坦诚」类干预，必须用 ground-truth 锚（角色真心是什么），不能用「表面敞开度」**——角色的藏 = 假敞开，表面判据被系统性污染（R2 用户+GPT 双盲判实证；R3 换锚后操控立现）。**这条对 rp/ 的 voice 评测台同样适用。**
2. **维度诅咒**：小样本高维，绝对 AUC 不可信，只看 trust vs placebo 相对 gap（R1）。
3. **负控制必备 + 量化共线**：third_person 与 trust **|cos|≈0.93**，不量化就会把「在场结构」误当 trust（R1 定性、R0′ 定量）。
4. **steering α 窗口窄**：扰动 norm ≤ 激活的 ~50%（L38 |α|≤1、L6 |α|≤1.5），过则退化成重复（R2、R6）。

## 悬而未决 / 下一步
- **解混杂只是「科学路」前置，不是工程决策前置**（见上「认识论教训」）：要**证明**纯 trust 方向是否存在，才需做配对样本（同场景同对象只翻 trust）把 `|cos(trust,3rd)|` 从 0.93 压下来——难点是 matched pair 在原著可能**不存在**（低信任=对手在场是语料焊死的），需**改写造**或**换天然解耦语料**。但对「决策走不走权重」这个已判负的工程问题，**边际为零，已叫停**。
- **投影替换（沿轴钉死坐标）测内核**：`ĥ = h − (h·d̂)d̂ + c·d̂`，把审判官 trust 坐标从 low 钉到 high——比加性更硬的证伪尝试。**但须先解混杂**，否则钉的大半是「在场结构坐标」，审判官不认罪无法区分「内核离轴」还是「钉错轴」。
- **状态机 / 时序机制**（PLAN 预判向量弱处）单独测——R5 已侧证「对象 / 情境逻辑不在向量」，时序同理待验。
- ground-truth 判读目前由 LLM 做，应配人工盲判 + 多例。
- **副产品**（非 exp2 目的）：对「外露向量 = 外露旋钮 × 对象基线 × 情境天花板」的刻画（RUNS R4/R5），可外推到其他模型——**合理推测，单模型未验**。
