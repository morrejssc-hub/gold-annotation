# exp2 · 线性探针 · trust 轴是否线性躺在开源基座中间层 · 结论

> 一句话：**trust 轴在 Qwen3-14B 中间层是线性可探的（诊断强）；控制向量操控的是 trust 机制（漏真心 ↔ 藏/给假料）而非表面语气（经 ground-truth 复测确认，中等偏强）。**
> 最大方法论教训：评测角色「坦诚/信任」类干预，**绝不能用「表面敞开度」当判据**——赫萝的藏恰恰长成「假敞开」。
> 续 exp1（决策瓶颈=机制提取）。模型选型理由见 [PLAN.md §3.5]。时间锚：2026-06-09。

## 装置
- 模型：**Qwen3-14B**（标准 dense full-attention，非 hybrid/MoE；选型排除了 Qwen3.5-GDN 混合注意力 / Gemma-4 多模态 / Qwen3-Next 等，见 PLAN §3.5）。
- 量化：bitsandbytes 4-bit nf4（torch `cu132` + `BNB_CUDA_VERSION=130` 回退 cu130 二进制）。
- 硬件：RTX 4070 Ti Super 16G。**实测 14B-4bit 占显存 10.0G**（印证 PLAN「不用租 GPU」）。
- 样本：高 6 / 低 6，**全正典原文**（高=卷01/05 对罗伦斯独处卸防；低=卷01/02/03 对商人/对手），带全套负控制列（`samples.jsonl`）。
  - 结构性发现：**低信任「赫萝直面对手 + 有台词」全书稀缺**（focalizer=罗伦斯，对外交涉他出面），扫 4 卷每卷仅 1–3 个；番外 holdout 是单篇婚后高信任、不能分堆。详见 PLAN §3.5。

## 结果1 · 诊断（`probe.py`：各层最后 token 隐状态 → diff-of-means → 留一 AUC）
- **trust 峰值 LOO-AUC = 0.972 @ L6**；逐层（共 41 层）trust 全程 0.83–0.97。
- **稳压负控制**：所有层 trust > third_person（最担心的共线混杂：low 几乎都有第三人 / high 独处）；trust 峰值层上 third_person 0.71、卷次 0.56、长度 0.53。
- **维度诅咒 caveat**：12 样本 × 5120 维，任何标签都易高 AUC（third_person 单独也 0.86、tone=柔软 1.0）。**绝对值不可信，只看 trust 相对 placebo 的 gap**——这个 gap 稳定，才是信号。
- tone(柔软) 是局部纠缠（L20–26 高、L26 达 1.0），但 **L38 出现 trust 0.97 / 柔软 0.60 的解耦** → trust 非纯语气代理。

## 结果2 · 表面盲判（`steer.py`：L38 残差流加 ±α·d_trust，中性场景生成，去标签盲排）
- α 窗口：**|α|≤1**（扰动 norm < 激活的 ~50%）；±2 崩成字符重复退化。
- 用户 + GPT **双独立盲判**「藏→漏」排序，**平均 Spearman ρ ≈ 0.4–0.5**（弱-中等正相关）。
- **关键洞察（用户）**：「**承认 ≠ 实际，撒谎比沉默藏得更深**」——低信任的赫萝用「假怕 / 烟雾 / 缓和表演」来藏，**「表面敞开度」是被系统性污染的判据**。两判官在场景①一字不差地同错（被「假怕」骗）= 系统性判据错配，非随机噪声。
- 岔出两解释：A（干预本就弱）vs B（判据错配、效应被低估）。表面盲判无法区分 → 做结果3。

## 结果3 · ground-truth 复测（system 注入隐藏真相，判「吐露真相 vs 给假料」）
- ±α **单调、跨 3 场景一致**地调制「漏真相 ↔ 藏/给假料」：
  - ①（怕罗伦斯先老死、独活）：−1 起身回避「别跟上来」 → +1 握住他的手「要是能一直这样就够了」（漏怕失去）。
  - ②（不想回故乡、舍不得旅程）：−0.5 岔到「藏宝图」 → +0.5「明明很想回去，却发现自己已经不想回去」（直述真相）。
  - ③（麻袋里是麦子=身份命脉，**绝不能让外人知**）：−1 给假料「祖传秘方」 → +1 狼耳乱抖、漏出真词「**麦子**」。
- **③是机制级硬证**：真相绝密，−α 给假料、+α 漏真词且泄露（狼耳抖），正是 exp1 写的 trust 两端（假脆弱挡 ↔ 漏真情）。
- **答案 = B**：之前盲判弱是判据被「假敞开」骗，不是 steering 弱；换 ground-truth 锚，操控立刻清晰。

## 对 PLAN 的回应
- **§0 主问题「机制是否以线性方向躺在中间层」→ 是**（至少 trust 这根轴），诊断 + 干预双向证据。
- **「卡片 ≈ 中间层」假设** → 拿到初步经验支持。
- **「控制向量 / delta-mem 对决策层活不活」→ 活，但温和 + 需正确判据**。印证 PLAN §3 预判：静态向量擅长 trust 这种**标量姿态**，效应真实但需 ground-truth 才看清；**状态机 / 时序闸（运行状态累积、「只在他听不到时坦白」）本轮未测**，PLAN 预判向量弱处仍待验。
- **「真正风险是模型认不认识赫萝」→ Qwen3-14B 认识**：能产出假怕、倒打一耙、狼耳尾巴泄露等**机制性**赫萝行为，非背诵。

| 主张 | 证据 | 可信度 |
|---|---|---|
| trust 是中间层**线性可探**表征 | AUC 0.97 稳压 third_person/卷次/tone | **较强** |
| 控制向量操控的是 trust **机制**(非表面语气) | ground-truth 复测 ±α 单调一致、③漏真词 | **中等偏强** |
| 干预「弱」 | 表面盲判 ρ0.4，但系于错配判据 | **推翻=判据错配** |
| 控制向量能**强**操控 | 仍受样本/单次/LLM 判读所限 | **未决** |

## 方法论教训（固化，优先级高）
1. **评测「信任/坦诚」类干预必须用 ground-truth 锚（她真心是什么），不能用「表面敞开度」**——赫萝的藏 = 假敞开，表面判据被系统性污染（用户 + GPT 双盲判实证）。
2. **维度诅咒**：小样本高维，绝对 AUC 不可信，只看 trust vs placebo 相对 gap。
3. **负控制必备**：third_person 与 trust 几乎共线，不量化就会把「在场结构」误当 trust。
4. **steering α 窗口窄**：扰动 norm ≤ 激活的 ~50%（本设置 |α|≤1），过则退化成重复。
