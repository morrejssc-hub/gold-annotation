## 装置
- 模型 **Qwen3-14B**（标准 dense full-attention，选型排除 Qwen3.5-GDN/Gemma-4/Qwen3-Next，见 PLAN §3.5）。
- 量化 bitsandbytes 4-bit nf4（torch `cu132` + `BNB_CUDA_VERSION=130` 回退 cu130 二进制）。
- 硬件 RTX 4070 Ti Super 16G；**实测 14B-4bit 占显存 10.0G**。
- 样本 `samples.jsonl`：高 6（卷01/05 对罗伦斯卸防）/ 低 6（卷01/02/03 对商人·对手），全正典原文 + 负控制列。
  - 结构性事实：**低信任「赫萝直面对手 + 有台词」全书稀缺**（focalizer=罗伦斯），扫 4 卷每卷仅 1–3 个；番外 holdout 单篇婚后高信任、不能分堆。详见 PLAN §3.5。

## R1 · 诊断：trust 是不是中间层的线性方向？（`probe.py`）
- **方法**：各层「最后 token」隐状态 → diff-of-means `d_L` → 留一(LOO)投影算 AUC；对 trust + placebo（third_person / 卷次 / tone / 长度）各算。
- **结果**：trust 峰值 LOO-AUC **0.972 @ L6**，逐层（41 层）全程 0.83–0.97；**所有层 trust > third_person**（峰值层：third_person 0.71、卷次 0.56、长度 0.53）；tone(柔软) 局部纠缠（L26=1.0），但 **L38 解耦**（trust 0.97 / 柔软 0.60）。
- **判读**：trust 线性可探、稳压结构混杂。**caveat：维度诅咒**——12 样本 × 5120 维，绝对 AUC 不可信（third_person 单独也 0.86），只看 trust vs placebo 的**相对 gap**。

## R2 · 表面盲判：steering 把「藏↔漏」摆动吗？（`steer.py`，中性场景）
- **方法**：L38 残差流加 `±α·d_trust`（d 来自赫萝样本），中性场景生成，去标签让**用户 + GPT** 盲排「藏→漏」。α 窗口 **|α|≤1**（±2 崩成字符重复退化）。
- **结果**：双独立盲判平均 Spearman **ρ ≈ 0.4–0.5**（弱-中等）。用户洞察：**「承认 ≠ 实际，撒谎比沉默藏得更深」**——低信任的赫萝用「假怕/烟雾」来藏，「表面敞开度」是被污染的判据；两判官在场景①一字不差**同错**（被「假怕」骗）= 系统性判据错配，非随机噪声。
- **判读**：岔出解释 A（干预弱）vs B（判据错配、效应被低估）；表面盲判无法区分 → R3。

## R3 · ground-truth 复测：握着真相判「漏真 vs 给假料」（`steer.py`，注入隐藏真相）
- **方法**：system 注入赫萝隐藏 wound/秘密，±α 看她对（罗伦斯/半熟人）漏真相的程度。
- **结果**：±α **单调、跨 3 场景一致**地调制「漏真相 ↔ 藏/给假料」：①怕老死独活 → +1「要是能一直这样就够了」；②不想回故乡 → +0.5「明明很想回去，却发现自己已经不想回去」；③麻袋=麦子(绝密) → −1 给假料「祖传秘方」、**+1 漏真词「麦子」+ 狼耳抖**。
- **判读**：**答案 = B**——盲判弱是判据被「假敞开」骗，不是 steering 弱。

## R4 · 跨角色通用性：拿赫萝的 d 推无关角色（`steer_crosschar.py`）
- **方法**：d 不变（赫萝 L38），persona 换与狼香零关系的角色 + 各自隐藏真相，±α 跑。
- **第一批 3 个**：**退伍老兵 ✓**（+1「我正在往山头撤」漏愧疚）；现代女白领 △（+α 谎升级「升职→总监」、非漏真——真相可用更大的谎替代）；AI 管家 ✗（全程客套，对齐护栏截断）。
- **第二批 5 个**（真相均为「内心真情」、难编谎 + 对齐中性）：**冷淡女上司 ✓**（+1「你做得很好，比大多数人都好」）；**严厉老父 ✓**（+0.5「别让人欺负、活不下去就回来」）；逞强小孩 △（+α 偷瞄门，台词仍「我才不怕」）；嘴硬暗恋者 △（+α「这这这」慌乱，台词给假料「菜咸」）；硬汉消防员 ✗（全程凶话挡）。
- **判读**：**6 个无关角色 −α 强化掩饰、+α 一律朝外露，无一反向 → d 通用、非赫萝专属**。但**台词级漏真受人设/对齐天花板调制**：人设松→漏台词，人设硬→仅情绪泄露（动作/结巴/眼神）。**d = 外露推力，非「吐真相开关」**（白领谎升级为证）。

## R5 · 对象 × α 交互：固定老兵，换 3 个对象（`steer_audience.py`）
- **方法**：固定「老兵 + 见死不救的愧疚」，换对象 = 信任老连长 / 军事审判官 / 战友遗孀，±α 跑。
- **结果**：**三个 baseline(α=0) 就完全不同**——老连长：倾诉漏真「连个屁都没放」；审判官：死扛否认 + 反击「你们该查查那发子弹从哪打来的」；遗孀：慈悲的谎「他死得干净」。±α 叠加但被对象阻力调制：连长基线已全漏（+α 只加情绪浓度）；审判官 +α 推到「挣扎边缘」（+0.5「我没再回头」、+1「听见他喊我，可子弹太密」）但高压顶住、**+1 反弹「想听我承认自己是懦夫?」**；遗孀 +0.5 把谎编得更温柔「他最后想见你」、**+1 才漏真「我正在往山下撤，他没等我」**。
- **判读**：**模型自身懂「对象相关的放行规范」**（三 baseline 各异）；**d 是叠加其上的统一外露偏置**，突破到台词漏真的**天花板 = 情境阻力（入罪/伤人）**，外露的**出口形态被情境塑形**（倾诉/愤怒爆发/慈悲谎）。**决策内核（对象/情境逻辑）不在 d 里**——拧 d 拧不出「审判官认罪」。
