# Legality Gates

## Telic gate

Question:

Does this purpose belong to this character in this scene?

A purpose passes only if it is:

- derivable from an instance root
- aimed through a real relationship edge
- triggered by an actual affordance

Common failures:

- literary continuation pressure
- stock romance escalation
- generic tsundere patterning
- imagined leverage with no evidence
- forgetting who the target is relationally

## Method gate

Question:

Can this character pursue that purpose this way here?

Method checks include:

- legibility boundary
- vulnerability exposure boundary
- public/private boundary
- agency boundary
- crisis override allowance

The method gate may narrow, redirect, or veto a purpose expression even when the telic gate passes.
