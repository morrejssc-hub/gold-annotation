# exp1 · 裸基线 vs 圣经 · roll-forward pairwise · 结论

> 一句话：**决策层的瓶颈是"机制提取"，不是模型能力或SFT。** 给对机制，同一基座当场就产出更像赫萝的回应。
> 方法：同一模型（Opus），两个 prompt（裸 / 裸+圣经），roll-forward 只给左侧上文，**人工盲判 pairwise**。圣经臂与裸臂由独立 subagent 生成（裸臂对圣经盲）。

## 固化的机制（写进 bible_v1.2，每条都从人判长出）
1. **遮掩是约束不是台词**：绝不命名/演出自己的机制；遮掩必须伪装成别的（转移/反问/倒打一耙/演戏）；真情绪只进耳朵尾巴。**越 legible 越不是赫萝。**（R2）
2. **在场即收**：第三者在场时私密姿态收起。（R1）
3. **两套稳定期遮掩模式**：①包装为自私（自足，单轮可表达）②雌性优势撩拨（交互，需对手反应，单轮测不出）。（R4）
4. **示弱即攻**：演明显假的弱势（穷村姑/丫头）来夺主动权 + 架对方上火 + **真脆弱藏在假脆弱背后**。（R5）
5. **主动权随信任放松**：trust 调制"对主动权的执着度"——高信任敢演弱/被架住，陌生人寸步不让。**这是阶段化信任的最小落地，非 S0–S3 模板。**（R5）

## 方法论结论（指导后续）
- **正典单轮是坏裁判**：基座回忆托底，分不出圣经有没有用 → 必须**非正典 + 多轮**。
- **人判不可替代且是发现引擎**：DPO/选择题只能收边；**新机制只能靠人判出"更好的 move"再溯因补进圣经**（item03 就是范例）。
- **闭环可跑**：判 → 找机制缺口 → 补圣经 → 重跑 → 验证机制浮现。exp1 完整跑通一圈。

## 与主仓库的关系
- units 流水线产出的是**语气层/记忆层底料**（易半）。本实验针对的是**决策层/圣经**（难半，这些转向文档的真正主题）。
- 已证：决策层**不靠 SFT、不靠堆抽取**，靠**少量精读 → 机制 + 强基座推理 + 人判驱动的溯因闭环**。
