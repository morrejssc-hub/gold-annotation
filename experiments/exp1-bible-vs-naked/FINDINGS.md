# exp1 · 裸基线 vs 圣经 · roll-forward pairwise · 结论

> 一句话：**决策层的瓶颈是"机制提取"，不是模型能力或SFT。** 给对机制，同一基座当场就产出更像赫萝的回应。
> 方法：同一模型（Opus），两个 prompt（裸 / 裸+圣经），roll-forward 只给左侧上文，**人工盲判 pairwise**。圣经臂与裸臂由独立 subagent 生成（裸臂对圣经盲）。

## 固化的机制（写进 bible_v1.2，每条都从人判长出）
1. **遮掩是约束不是台词**：绝不命名/演出自己的机制；遮掩必须伪装成别的（转移/反问/倒打一耙/演戏）；真情绪只进耳朵尾巴。**越 legible 越不是赫萝。**（R2）
2. **在场即收**：第三者在场时私密姿态收起。（R1）
3. **两套稳定期遮掩模式**：①包装为自私（自足，单轮可表达）②雌性优势撩拨（交互，需对手反应，单轮测不出）。（R4）
4. **示弱即攻**：演明显假的弱势（穷村姑/丫头）来夺主动权 + 架对方上火 + **真脆弱藏在假脆弱背后**。（R5）
5. **主动权随信任放松**：trust 调制"对主动权的执着度"——高信任敢演弱/被架住，陌生人寸步不让。**这是阶段化信任的最小落地，非 S0–S3 模板。**（R5）

## 方法论结论（指导后续）
- **正典单轮是坏裁判**：基座回忆托底，分不出圣经有没有用 → 必须**非正典 + 多轮**。
- **人判不可替代且是发现引擎**：DPO/选择题只能收边；**新机制只能靠人判出"更好的 move"再溯因补进圣经**（item03 就是范例）。
- **闭环可跑**：判 → 找机制缺口 → 补圣经 → 重跑 → 验证机制浮现。exp1 完整跑通一圈。

### v2.0/v2.1 机制迭代链（本轮决策侧主要产出·人判驱动）
- **v2.0（item06 长出）**：把"藏与不藏（揭开/直白度）"并进 **trust 轴**——与"对主动权执着度"同轴；高信任×日常脆弱→**敢漏一句近直白再封顶**，别纯交易化藏过头。锚卷5 30_236–238。
- **v2.1（item09 长出）**：漏一句**≠终态**；中高信任下漏完须**倒打一耙夺回主动权**（=示弱即攻用在漏口上），绝不软下去（退让/心理剖白/求理解/downplay 自抹）。危难场景(§6b)除外=真坦白。锚卷4 12_134/12_139。
- **机制→行为再验证（第 5、6 次）**：A 重跑 v1.9→v2.0 漏口长出（"害怕"一词浮现）；D 重跑 v2.0→v2.1 倒打一耙夺回主动权长出（戳额头+"迟钝的雄性、欠咱的记着还"）。**人判refine→编码→同模型当场复现**，再证瓶颈在机制。

### 第二轮结论
- **圣经净贡献在正典单轮也判得出（部分反例于"正典单轮废裁判"）**：因对照的是**裸臂**（不是圣经v0），裸臂"过满/乘胜追击/legible/直接示好"的病很显眼，圣经臂"迂回/点到/化外压为试探"稳定更像 → **决策三战三胜**。但圣经臂普遍**藏过头**：比正典更不敢亮牌(B)、更不敢漏一句近直白(A)。
- **语气侧（本轮主轴）首批积累 2 个干净残差，同类病**：①**台词长难句/长连续句**——正文赫萝台词偏短、**句间插小动作当节拍**；②**用词火候**偶失（"窟窿"）。**Opus4.8+语气few-shot 仍不能稳定落地这两条**（voice_gold #1 已写"留白/节奏"但提示词没执行到位）→ **初步支持"提示词封顶、语气该上 craft-edit gold / 语气 LoRA"**。样本仍少，继续积累（用户定调"语气侧少先积累"）。
- **方法论修正（rig 必固化）**：subagent 场景 framing **一律中立化**——只给中性事实（同行多久/在场谁/公开私密），**禁用"暧昧/亲密/情色"等情绪关系形容词**（item08 实锤污染两臂）。R1 在场即收被正典再确认。
- **待人判的候选机制**（未编码，防铁律7过拟合）：卸防分级在**日常脆弱+独处可信**时，是否允许"**漏一句近直白→自嘲一词/比喻封顶**"（锚卷5 30_236–238「咱很害怕…因为汝的…温柔。」）。

## 与主仓库的关系
- units 流水线产出的是**语气层/记忆层底料**（易半）。本实验针对的是**决策层/圣经**（难半，这些转向文档的真正主题）。
- 已证：决策层**不靠 SFT、不靠堆抽取**，靠**少量精读 → 机制 + 强基座推理 + 人判驱动的溯因闭环**。
