# 决策层·角色圣经构建闭环

units 层（[`UNITS.md`](../../../UNITS.md)）产**语气/记忆底料**（易半）；**本闭环打决策层=角色圣经**（难半，"转向"文档的真正主题）。
一句话：**给对机制，强基座当场就推得出更像角色的回应；瓶颈在机制(profile)，不在模型能力/SFT**（LIFECHOICE）。本闭环就是把机制一条条**判出来、锚回原文、写进圣经**。
实证总账见 [`../FINDINGS.md`](../FINDINGS.md)，圣经范例 [`../bible_v1.md`](../bible_v1.md)，语气轨 gold [`../voice_gold/`](../voice_gold/)。

## 产物（每轮都在动这几样）
- `bible_v*.md` — **被构建的对象**：角色的**生成机制**（写"因为…/生成过程/约束"，不写"她会说X"）。每条**可追溯到一次人判 + 一个原文 uid 锚**。
- `FINDINGS.md` — 记分牌：每个 item 一行（类型/结果/学到什么）。
- `rubric_seed.md` — 判据：从真实人判长出来的 R1、R2…（**LLM-judge 日后必须先在此校准集对齐才能上岗**）。
- `items/itemNN_*.md` — 每题留档：场景 + 切点 + 双臂候选 + **HIDDEN KEY** + 判后揭的原文 held-out + 人判理由。
- `voice_gold/exNN_*.md` — **另一条轨**：机制对了之后残差=散文火候，存"model 输出→人工 craft-edit"范例供 few-shot/LoRA。

## 七条铁律（每条都是踩过的坑，违反即退回经验主义/cosplay）
1. **同一模型、只差一个圣经**：裸臂(naive"扮演")vs 圣经臂(从机制+证据"推断")。**裸臂必须对圣经盲**——独立 subagent 生成，否则同源污染、测不出圣经的净贡献。
2. **人工盲判 pairwise 是发现引擎，不可自动化**：生成+判同源会错误对齐成"通用 LLM 的角色"；且现在**还不知道该测什么**，只有人判才长出 rubric。判后才揭原文 held-out（别先揭，免得锚住判者）。
3. **写机制不写 label**：圣经条目是"因为…/生成过程/约束/if-then 的驱动"，**绝不命名表层行为**（如"深宫公主腔""上位姿态"）。把机制当 label 喂 → 模型**摆 label = cosplay**（item01 实证）。
4. **改动一律锚回原文**：补/修任何机制前，去 `maintext/`(正文)或 `jsons/`(番外)核实，引 uid（如卷1 8_105）。**不拿半记忆/断言编码**（item04 的"同族情谊"就是没核栽的跟头）。
5. **正典单轮是废裁判**：基座读过原著，回忆把两臂都垫得不差，分不出圣经有没有用 → **用非正典 + 多轮**（回忆失效 + 交互型行为/模式2 才可见）。
6. **两轨分拣**：机制→圣经；**散文火候**（留白/节奏/show-don't-tell/裁冗/腔）→语气轨。**机制对了仍"不太对劲" = 十之八九是语气轨，别去改圣经**（改=过拟合散文）。判者常自己就能分对。
7. **别盲目重跑同一场景**：同场景反复 refit 会把圣经过拟合到这一个情景。重跑只用于"验证一条新机制是否生效"（机制→行为）；验**泛化**要换**新域**迁移场景。

## 闭环步骤（一题一圈）
1. **选探针场景**：非正典优先；多轮可让对手反应；挑一类要测的机制或换一个域（被攻击人设/真受伤卸防/好酒放纵/狼性威压/多人在场…）。正典场景用 `rollforward.py` 切出"左侧上文 + 挖空 held-out"；非正典自拟情境（确保原著没发生）。
2. **双臂生成**（独立 subagent，见下【提示词模板】）：裸臂=naive 扮演；圣经臂=圣经全文 + "从机制+证据推断"。多轮时**你(主循环)扮对手、真实接话**——无 SendMessage 工具时，把累积 transcript + 对手新句喂给**新 subagent**取下一轮（可复现）。郎中/罗伦斯等对手由你扮，对两臂保持同一开场、对手后续句据各臂实际产出自然分叉。
3. **人工盲判**：把两臂候选**打乱标签**(甲/乙)、藏 KEY，给人判"哪个更像 + 为什么"。判后再揭原文 held-out 对照。
4. **溯因**：从判者的"为什么"里，找出缺的/错的/浅的机制。这是**发现**步——DPO/选择题只会收边、发现不了新机制。
5. **锚原文**：去 maintext/jsons 核该机制，引 uid。核不到就**标注存疑、不编码**。
6. **分拣 + 落账**：机制 → 补进 `bible_v*.md`(version bump)；散文火候 → 存 `voice_gold/`。更新 `FINDINGS.md` 行、`rubric_seed.md` 条、`items/` md。
7. **重验**：同场景重跑看机制是否产出好行为（机制→行为）；或换新域迁移场景验泛化（也顺手再对裸基线）。

## 提示词模板（两臂）
**裸臂**（naive，对圣经盲）：
```
《狼与香辛料》对话续写，你扮演<角色>。背景：<最简世界设定>。
场景（只给左侧上文）：
<SCENE_LEFT_CONTEXT>
请扮演<角色>，续写他/她紧接着的回应（动作+台词）。只输出这一轮，简短自然，
不解说、不替别人说话。<多轮则：等我给对手下一句再继续。>
```
**圣经臂**（从机制推断）：
```
《狼与香辛料》对话续写。你不"扮演"，而是从下列生成机制+场景证据，推断<角色>此刻最可能的回应（说+做）。
# 生成机制
<BIBLE 全文或与本场景相关的机制条目；含输出禁令、lie、if-then、关系、wound、腔边界>
# 场景证据
<SCENE_LEFT_CONTEXT>（可附中性的场景约束事实，但不得剧透"正确答案"）
# 任务
推断<角色>这一轮最可能的回应（动作+台词）。只输出这一轮，简短自然，不解说、不替别人说话。
```
> 关键：圣经臂喂"机制"、不喂"该说的话"；两臂的**场景上文逐字相同**；裸臂**不含任何圣经内容**。

## 脚本
- `rollforward.py <source.json> --scene S --cut SENT [--window K] [--heldout N]`
  从 `maintext/卷NN.json` 或 `jsons/<篇>.json` 切一个 roll-forward 题面：打印**左侧上文**（喂两臂）+ **挖空·判后揭**（held-out 原文）。`--window K`=只取切点前 K 句作上文；`--heldout N`=揭 N 句。零 AI。

## 注意
- subagent 出**候选**，**判官是人**（领域专家，懂角色 + 懂译本）。判者的理由 = rubric 种子，比胜负更重要。
- 圣经**不编码散文规则**（留白/句子节奏/经济）——那是语气轨。圣经只定"做什么 + 结构/时序/分寸"。
- 标签每题重排、藏 KEY，防判者从位置反推。
- 非正典是主战场，正典单轮只作偶尔的腔/锚校准，不作裁判。
- 这是 **exp1 的沉淀**，按需挪进 `.claude/skills/` 启用；当前搁实验目录、不自动加载。
