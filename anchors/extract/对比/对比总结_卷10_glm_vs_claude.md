## 一、两臂范围切法差异

两臂对卷10「关系不是连续大弧、是旅途终点逼近下的散点窗口」这一判断**完全一致**，但切的窗口宽窄和密度差别很大。

| 退化条款 | 明确声明用过：先 `--list-scenes` 生成客观分幕目录再回头精读（卷长，怕中段商战漏判） | 未声明分步，称「API 直调一步生成」 |

## 二、读法收敛 / 分歧 / 互补

### A. 双臂都说、且都扛过对抗 → 高置信

1. **本卷是卷05「我喜欢你」沉默留白的回答闭合，不是 trust 数值跃迁。**
   两臂独立给出且措辞高度一致：claude 读法三「不是 trust 跃迁」+ §八第3条；glm §八第3条「从知道但不说，到知道且说了的闭合，花了整整五卷才送达」。两臂都引 s43:99–101 留白、都明确赫萝「最喜欢」≠正面承诺。核查：两臂此处引文均逐字属实、留白如实保留（无后卷倒灌）。对抗：claude 读法三扛过、glm 此条未被列入对抗削弱项。**收敛 + 双扛过 = 高置信。**

2. **罗伦斯用「商人理性 / 实际理由」包装情感、认知滞后于行动。**
   claude 细节(5)+读法二雏形（「不抱希望不去期待…胆小鬼心理」）；glm 读法二 + V10-W1（双面模式）+ 细节2（「对自己感情的认知滞后于行动」）。glm 这条挖得更系统（s0 顾客 / s14 商人铁则 / s26 伤不伤感 / s40 将错就错 一路串）。对抗：glm R2 是「全卷支撑最厚、扛过反驳」的一条（s40:76 出生入死的行动反证「本来没那么强烈」的替代解释）。**收敛 + glm 侧最扛打 = 高置信**（claude 侧此点稍欠系统、但方向同）。

3. **艾莉莎不是工具人，是同构镜像（自己也卡在「原则 vs 真心话」）。**
   仅 glm 精读了 s37–38（claude 把 s13/s15 艾莉莎归梗概、没展开 s37–38），所以严格说这条**不是双臂收敛**——但 glm 独占的这条对抗扛过（R5 卷10 内扛过，s37:117「真心相爱」命名 + s37:120 罗伦斯捂脸属实），且填补了 claude 的盲区，归到下面「互补」更准。**此处先标：glm 独有 + 扛过 = 中-高置信，待 claude 侧无对照故不升「双臂收敛」。**

### B. 分歧 / 同一处证据读法不同 → 需人裁

4. **s21 的施动方向：谁先拆面具？**
   - claude：罗伦斯「主动看穿、点破赫萝发火的真实结构」，但**当场就自疑**「如果她仍唯独想撒娇呢…适得其反」（claude 把这条不对称专门列为「并存张力，先不裁决」，细节(3)展开）。
   - glm：直接称 s21 是「罗伦斯第一次正面拆赫萝的贤狼面具」「面具被命名」。
   - **对抗结论给了关键裁决材料**：glm 对抗 R1 **被削弱**——canon s21:60 叙述层「赫萝**摘下了**这样的面具…罗伦斯就应该勇敢地这么想」，即**面具是赫萝先摘、罗伦斯后命名并推**。glm 正文「罗伦斯首次拆面具」的施动方向与 canon 相抵（glm §八第2条自己也承认「从背后推一把」，正文口径不一）。
   - **此处 claude 的处理实际更贴文本**：claude 没说「罗伦斯主动拆穿」是确定事实，而是把它当作「可能弄反了」的并存张力留着。
   - **人裁点**：合并稿写 s21 时，施动方向应采「赫萝先松/先摘、罗伦斯命名并推一把」，把 glm「首次正面拆」的强措辞降级，保留 claude 的「劝人别装＝理解还是否定撒娇资格」这条不对称。

5. **s21:160「以后出了啥事都不是咱的责任」怎么读？**
   - claude：读成「都是汝的错」的伏笔，在 s43:131 回收为离别焦虑的脾气。
   - glm：读成「把任性许可变成一道免责声明」（暂时读法 A：面具变形）。
   - **对抗结论**：glm 对抗 R1 附带硬点指出——「免责声明」读法**被削弱**，因为它**选择性截断**了 s21:163「呵呵，开玩笑而已」、s21:166「偶尔不去考虑那么多也不错」（赫萝当场自己撤回了语气）。claude 的「伏笔→s43 回收」读法没有依赖截断、且回收点 s43:131 经核查属实。
   - **人裁点**：claude 的「伏笔」读法证据链更干净；glm「免责声明/面具变形」需补上 s21:163/166 的当场撤回，否则强度过头。两条不互斥（可以既是当场玩笑、又是 s43 回收的伏笔），但 glm 的「变形成新交换」说法需要降级。

6. **「怕分离的承受方」：对调漂移 vs 始终对称。**
   - claude：读法一「角色互换重演」+ 弱模式 A「怕分离会从能动性弱的一方**漂移**到另一方」。claude 自己已埋边界（s43:73/131 提示赫萝也一直怕，「漂移」可能高估对调彻底性）。
   - glm：没有「角色漂移」这个提法；glm 的对应处理散在 V10-W1（赫萝把情感需求放最后）和读法四（赫萝一直在等他追上来）。
   - **对抗结论**：claude 对抗读法一/弱模式 A **被削弱**——「漂移」过强，s35「释然」只是罗伦斯单方观察、原文从无赫萝「我已放下」的独白；替代解释「两人始终对称地都怕，罗伦斯被一条假信息骗进单方焦虑」更省。
   - **人裁点**：合并稿应采「**表面承受姿态对调，但双方始终对称地怕分离**」，把「漂移」这个跨卷动力学措辞降级（claude 自己已在 §八第1条这么写，正文读法一与弱模式 A 的强措辞需向边界看齐）。

### C. 互补、可拼 → 合并后更完整

7. **claude 的「物件代替直说 / 空白契约书回指卷03」 + glm 的「s1 小小的打算 → s43 信」= 同一根伏笔线的两端。**
   - claude 强在「空白契约书」的**结构回指**（回指卷03 阿玛蒂监护人栏空白的结婚证书：卷03 是赫萝用空白契约逼罗伦斯喊「别结婚」，本卷是罗伦斯用空白契约求赫萝填「愿意继续同行」）。
   - glm 强在「这封信的**来源**」——s43 犹古信正是 s1:27–32 罗伦斯一开始就拜托犹古写的「小小的打算」（核查确认 s1→s43 回指准确），证明「罗伦斯对未来的想象从来不是『送到约伊兹就结束』」。
   - **拼起来**：罗伦斯从卷一开头（s1 的打算）就在为「赫萝留在人类世界」埋伏笔，到 s43 用「签名的空白契约书」（既是举证、也是求回复）递出——claude 给了「这是什么手段（空白契约/回指卷03）」，glm 给了「这手段从何时开始铺（s1）」。两端互不矛盾，合并后是完整的一条跨卷伏笔。
   - **共同需保留的边界**（两臂对抗都指出）：claude 对抗——「继承赫萝造局术」过度类比，罗伦斯版本性质是**举证/自我袒露**（「我的心你还不明白么」），不是赫萝那种**押代价的逼问**，烈度差是真的。所以拼合时保留 s43:165 的文本事实（原文旁白直给「希望得到回复」），但不要写成「罗伦斯继承了赫萝的工程化逼说手段」。

8. **claude 的吃醋分层（s07 看板娘 vs s21 艾莉莎，焦虑对象不同别焊死） + glm 的 s26/s31 决策—等信链 = 卷10 关系全貌的两半。**
   - claude 独有且**最扛打**的观察（对抗判定「最稳」）：前半吃醋戏不是一条线——s07 看板娘是「怕罗伦斯被勾走」、s21 艾莉莎是「怕柯尔被分走（被需要的位置）」，焦虑对象不同，别都塞进「离别焦虑」。
   - glm 独有：s26 赫萝选瑾仙的决策峰 + s31 寒夜等信「想一起看地图」+ s32 替柯尔着想的判断 —— 这条「赫萝用理性决策替所有人着想、唯独没替自己」的链，claude 几乎没碰。
   - **拼起来**：claude 管「赫萝怕失去在场位置」的**散点前置烟雾**（吃醋分层），glm 管「赫萝把自己放最后的理性退让」的**主链**（决策—等信—告白）。两者都服务「旅途将尽的离别压」，但一个是烟雾、一个是主链，合并后才是卷10 关系的完整骨架。

## 三、并置才浮出的新读法（重点）

> 单臂各自没说全、两份并排才看出来的。仍标临时、非定稿、归人。

**N1（强）｜「被需要的焦虑」（赫萝侧，s3）与「无容身之处的焦虑」（罗伦斯侧，s35）是同一种存在级恐惧的镜像两端。**
- claude 重点锚了 s03:16「不被需要是几百年噩梦」（赫萝怕被柯尔/芙兰取代在场位置）；glm 重点锚了 s35:145「在他们之间根本没有自己的容身之处」（罗伦斯怕进不去赫萝的狼世界）。
- 两臂各自都没把这两处接起来，但并排看：**赫萝的「不被需要」和罗伦斯的「无容身之处」是同一句话的两个主语**——都是「我在对方的世界里没有不可替代的位置」的恐惧。卷10 的结构妙处正在于：上半场是赫萝怕（s3 柯尔暗线），下半场翻成罗伦斯怕（s35 穆里），**同一种恐惧在两人之间换了一次主语**。这比 claude 单说的「怕分离角色互换」更深一层——互换的不只是「怕分离」，是「怕自己在对方世界里没有位置」这个更底层的东西。
- 边界：这是两份并置后的归纳，**原文未把 s3 与 s35 明接**，须标「跨臂综合、非文本事实」。且 N1 不能反推「赫萝释然了」（对抗已削弱），只说恐惧的**形式**对称。

**N2（中）｜两人各自的「面具」结构同构，且 s37 艾莉莎一句话同时戳穿两副面具。**
- glm 细节3 已点到一半（赫萝的贤狼面具 ＝ 罗伦斯的商人理性 ＝ 同一种「用『这是正确的选择』回避『这是我不想做的选择』」）。
- claude 没用「面具同构」这个框，但 claude 细节(5)独立观察到罗伦斯「靠自己、不强求」的商人姿态在关系上变成「不敢信任对方主动性」——这其实就是 glm 说的「商人理性面具」的**具体机制**（不只是回避，是把自我保护伪装成体面）。
- 并置后：glm 给了「两副面具同构 + 艾莉莎 s37:44『真心话写在脸上、嘴边挂着原则』一句双戳」的框架，claude 给了罗伦斯那副面具的**内在矛盾细节**（s14 体面 vs s43 胆小鬼）。拼起来是「**贤狼面具 / 商人面具是同一台机器的两个出厂型号，s37 外部命名者同时拆了两台**」。
- 边界：glm 对抗 R1 提醒「面具脱落」的施动方向别写反（赫萝先松）；N2 只说「结构同构」，不主张「罗伦斯主动拆」。

**N3（中-存疑）｜赫萝的「债务/契约」措辞在卷10 反向使用——从卷01「还清即自由」翻成卷10「替对方找台阶」。**
- glm 细节4 独有：s26:26 赫萝拉旧债当挡箭牌，但「这次方向反了」——卷01 是赫萝用债务试「可不可结清（脱身）」，卷10 是赫萝用债务**替罗伦斯找体面分手的台阶**。
- claude 没碰 s26（漏了这个窗口），但 claude 的「空白契约书回指卷03」与 glm 这条**同属「契约框架在卷10 被翻转使用」的母题**——claude 管「物件层（空白契约）」，glm 管「话术层（旧债当挡箭牌）」。
- 并置浮出：**卷10 把『契约』这个赫萝-罗伦斯关系的原始隐喻，在话术层（赫萝用债找台阶）和物件层（罗伦斯递空白契约求回复）两处同时反向使用**——契约不再用来「界定/结清关系」，而是用来「把关系定义权交给对方」（glm 细节7「空白＝你填什么都行」）。
- 边界：标存疑——claude 未独立验证 s26，这条主要靠 glm 单侧 + claude 物件层旁证；契约母题的跨卷对照需与卷01/03 并置才稳。
