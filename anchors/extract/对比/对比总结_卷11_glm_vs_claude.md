## ③ 并置才浮出的新读法（重点）

这些是单看任一臂都不显、两臂并排才浮出的东西：

### 新读法 1（高价值）：「不只是等待 / 介入式陪伴」存在**两种触发伤型**，且罗伦斯的合用动作不同

- claude 的 W1 只在**前半哀悼伤型**（s08–16 失同伴）下观察：伤来自外部/时间 → 罗伦斯介入式陪伴（拉出门/张罗实事），且配时序条件（最痛当下先放手独处）。
- glm 的 s36 / s61 揭示**第二种伤型**：伤来自**关系内的根本不对称（寿命）** → 此时赫萝要的不是「被拉出门散心」，而是罗伦斯**主动接过决策权与责任**（s36:249「那这样，你不需要做决定」）。
- **并置浮出**：罗伦斯的「介入」在两种伤型下形态不同——哀悼伤型＝介入式陪伴（行动层），寿命/责任伤型＝接过决策权（承诺层）。claude 的 W1 只覆盖前者。这条提示 W1 若要升格，**触发条件须按伤型分层**，且「接过决策权」这一动作 claude 臂完全没看到（因未精读 s36）。
- **重要边界（来自 glm 自身对抗）**：s36「我会负起责任」不可当字面承诺，功能是「把赫萝从独自做决定的恐惧中解放」，不是「替她扛 forever」。升格时须带此边界。

### 新读法 2（中价值）：「确信被喜欢」（claude·罗伦斯侧）与「得到之后的责任」（glm·罗伦斯侧）是同一认知曲线的**前后两段**

- claude s19：罗伦斯第一次「能抬头挺胸说赫萝是喜欢我的」——**内部确定性沉淀**（前半）。
- glm s61：罗伦斯察觉「想得到某人的心，与得到后想保护那个人完全是两码事」——**认知转折**（中后段）。
- **并置浮出**：罗伦斯本卷走的是「先坐实『她喜欢我』（s19）→ 再撞上『得到之后我还没准备好负责』（s61）」的**两段式认知曲线**。单看 claude 会以为本卷罗伦斯的关系认知在 s19 已稳态；单看 glm 会以为 s61 是凭空转折。并排才看出 s19 的「确信」恰是 s61「天真」的前提——他先确信得到了，才会暴露出「以为得到就是终点」的天真。这条**两臂都没单独说出**。

### 新读法 3（中价值）：s28「咱也不会在意」的**自承层**改变了 claude「确信被喜欢」的读法基底

- claude 把 s19 读为「赫萝当场在吃醋+嘴硬，纯属罗伦斯单边确信」。
- glm 对抗揭出 s28:84 被 glm 自己**选择性截断**：原文赫萝当场承认「一旦知情就会很在意……不过事情也不可能因为没去看就不会发生」——即赫萝是**自觉在意、以回避维持**，不是「不自觉/压抑」。
- **并置浮出**：claude 在前半把赫萝读成「间接、嘴硬、靠罗伦斯接住」；glm 的 s28 自承层显示赫萝其实**对自己的在意高度自觉**，只是主动选择不说破来推罗伦斯追梦。这让「赫萝绕弯=不自觉/含蓄」的读法被削弱——她绕弯是**清醒的策略选择**。⚠ 注意：s28:84 的自承句被 glm 截断、需以核查/对抗结论的「自觉在意以回避维持」为准。

### 新读法 4（存疑·需回 canon）：s3:59 的归属冲突直接影响「特别性追问」读法

- claude §3「s03 赫萝用玩笑反向确认『不是看外表选你』」与 glm §3.2「s3:59『我会选你也不是看外表』是赫萝绕路确认选择罗伦斯超越外表」——**两臂都把这句读成赫萝侧的『特别性』确认**。
- **但 glm 对抗已自判此处被推翻**：canon s3:59–62 显示「我会选你也不是看外表？」实为**罗伦斯**所说（礼尚往来回敬），且 s3:61「赫萝拒绝接受发言的态度让罗伦斯闭上了嘴」——赫萝是**拒绝**正面接受，不是确认。
- **并置浮出的风险**：两臂在前半都依赖这句支撑「卷02 特别性追问在本卷得到确认」（claude 读法C / glm 卷02 接点）。该句被推翻后，**这条跨卷接点在 s3 失去支点**，但 claude 的 s19「绝不是受信赖/被看重那种喜欢、不牵扯损益」仍独立成立。⚠ **需回 canon 重定位 s3:59 归属后，重审「特别性追问在本卷确认」这条跨卷读法的证据基底。**

### 主轴怎么串（一条线把两臂拼起来）


### 拆哪几个主题原子（候选，归人）
