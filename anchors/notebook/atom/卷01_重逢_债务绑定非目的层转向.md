# 卷01 · 重逢：债务绑定，非目的层转向（scene39 终幕）

> 旧 notebook 当物流跳过的终幕。本卷关系**真正的收束**。

**主题**：scene10 的原约是松的（她自付餐费、不欠他什么、随时两清走人）；到 scene39，账翻了过来——**她现在欠他**（救命、被撕掉的衣服）。「先还清欠债再回北方」给这段同行装了一个「得继续走下去才能了结」的**结构性理由**。**那份松约被翻成了一个自带续航的债务绑定。**

**跨 scene 证据**：
- 罗伦斯醒来一度以为赫萝已独自上路（s39:42-44），是那张写着「豪华女用长袍两件、玳瑁梳、大量苹果、**却没有马车一项**」的请款单（s39:160-165）让他冲到卸货场。
- 赫萝坐在堆满苹果的驾座上梳尾巴、不肯看他、赌气：「咱可不想被人讨债讨到北方来」（s39:174）；罗伦斯伸手，她瞥一眼、最终缓缓伸手——「咱会先还清欠债再回北方」「这还用说吗！」，「赫萝紧紧地、紧紧地握住罗伦斯的手」（s39:178-181）。

**简单分析**：
- **「正式化」太中性，准确说是「松约被翻成自带续航的债务绑定」**（读法）：scene10 是「随时可两清」，scene39 变成「债没清前散不了」。用的语言仍是债（罗伦斯先用「讨债」留人 s38，赫萝再用「还清欠债」接住 s39，[主轴](卷01_主轴_债与契约作为安全语法.md) C1 在 s39 的功能＝**给继续同行找台阶**）。
- **目的层（回北方）一点没动**（原文 + 复杂化反例）：这跟卷三「目的层转向」（约伊兹哪怕不存在也一起去）有**本质差别**。卷一只给同行装上债务续航，卷三才拆掉边界、把落点从坐标挪到关系。**卷一结尾不是卷三转向的前身**，但「她不断找新债留下」这条线的源头在这（架构线 C 接口）。
- **「债」的壳功能＝绕开两笔没付的账**（落点收口）：他怕她真身、自承没化解（[畏惧真身](卷01_畏惧真身_没化解的别扭.md)）；她被弃过、刚又被叶勒当面「诀别」（[被弃史](卷01_被弃史_序幕到叶勒诀别.md)），半防着再被弃。两笔账谁都没当场结——没有「我不再怕你 / 我不再怕被你丢下」的和解。**真正让关系仍能成立的，是「债」这个壳：债不要求他不怕她、只要求他为钱追她；不要求她敢赤裸依赖、只要求她欠着还着。** 这就是「延后付款的同行」——一段建在还没到期的账上的羁绊。
- **最小翻转对候选素材**：scene10 松约 vs scene39 债务绑定（同对象、关系位置从「随时可两清」翻成「债没清前散不了」）——翻判型留人审，本稿不主张新增字段。
