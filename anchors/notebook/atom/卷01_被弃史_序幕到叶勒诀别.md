# 卷01 · 被弃史：从序幕到叶勒「诀别」（s00 / s08 / s34）

**主题**：赫萝的旧伤**先于罗伦斯**。序幕里抽象的「村民已不再需要咱了」，在 scene34 被一个她认识的人（叶勒）**当面、主动**落成实锤。这笔「被守护对象抛弃/不再需要」的旧账是她**关系行为的重要底色**（不吞掉她的好奇/骄傲/玩心/捕猎智慧/旅行欲——那些不归这条线），也是 exp4 根 R1（孤独诅咒）的正典实例。

**跨 scene 证据（从抽象到实锤）**：
- **序幕（s00，背景音）**：守帕斯罗村几百年的丰收之神，村民引进南方新农法后「已不再需要咱了」。
- **s08（亲口补全）**：当年答应村里年轻人让麦田丰收，信守几百年，但村民一遇歉收就骂她反复无常——「那地方根本不需要咱，那些家伙也不需要咱」（s08:219）。
- **s34（现场实锤）**：抓她的人里有**叶勒**——帕斯罗村她认识的人。她守那村子几百年（「或许有咱尾巴毛的数量那么多的年数」s34:105），被供着、其实更像「被村民拘留」（s34:109）。叶勒从杰廉口中听到她名字时本「想到该不会是咱」，她「那时听了真的觉得很开心」（s34:118）——随即被同一人一刀斩断：**「我们必须看你心情好坏过日子的时代已经过去了……不如就把你交给教会，让我们与旧时代诀别吧！」**（s34:120）。她低头落泪（s34:119,127）。

**简单分析**：
- **她怕的是一种具体形状的孤独**（读法）：不是抽象孤独，是**被自己守护/在乎的对象判定为不再需要**。这解释了为何[开店梦](卷01_开店梦_不想再一个人.md)里罗伦斯「你一个人旅行也没问题」会精准戳中她——无意复制了「你不需要我同行」的判定。
- **s34 是序幕旧伤的实锤版**（原文）：不是悄悄冷落，是一个她认识、曾让她「开心」的人，亲口要把她交给教会、与她「诀别」——**而且就发生在她马上要冒险变身救局/护他的前一刻**（她有变身能力与一定把握，不写成「赴死」）。
- 罗伦斯的回应是「用商人语言接住」：擦她眼泪，「我，不！**我们**是商人……哭完后，我们还是会笑」，刻意加重「我们」（s34:133-134）；赫萝瞬间看他一眼、再落泪（s34:135）。**在她刚被旧「我们」（村子）踢出来的当口，罗伦斯递的正是一个新的「我们」**——仍裹在生意话术里（见[主轴](卷01_主轴_债与契约作为安全语法.md)壳底下的驱动）。
