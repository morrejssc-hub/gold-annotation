# 卷05 · 主轴：可结清 → 不可结清（含「秤」的反框）

**主题**：本卷脊梁——关系从「可加减归零、可结清退出」挣脱到「结不清、退不掉」。一对张力：赫萝**害怕关系继续活下去会磨耗美好，于是试图把它封存成一个可干净退出的美好故事**；罗伦斯经一系列事件后**发现他不想让这段关系被结清**。

**跨 scene 证据**：
- s01：「上秤」是**赫萝的恐惧**（s01:121）、赫萝自探其重（s01:123）；罗伦斯的反应是**不去秤、断定她不轻**（s01:125）。「两种行动基准（赫萝/商人）」＝商人(可秤)模式 vs 赫萝(不可秤)模式，**不是罗伦斯在秤她**。
- s20:104：全卷唯一一次正面用「秤」，是赫萝叫罗伦斯把**利益 vs 风险**上秤，并把自己拿下秤。
- s20:156–158：罗伦斯过往关系都「加减归零」（借出→偿还，朋友→信赖），与赫萝是**全新的关系**；他找到字眼时赫萝皱眉「不需要说出来」。
- s30：赫萝「体面收场」＝想把不可结清的新关系**塞回可结清旧框**以便干净退出。
- s38：罗伦斯输掉账面＝**让账永远平不了**。

**简单分析**：
- 呼应并收束前作：**卷01 还债、卷02 还钱即自由**——「还清＝结清＝可分开」是旧关系算法，本卷在拆它。
- **分清两条轴**：s13「咱也一样」是**占有欲/嫉妒**对称（真），≠「怕被秤重双向」；别拿占有欲对称当上秤对称的证据。
- 赫萝真正发火点（s20「伙伴还是玩赏物」）＝「别绕过咱的意志，把咱当可处置的交易附件」；「秤」是更上层的旧关系框架，不要吞掉 s20 的具体伦理点。
