# 卷02 · 终幕复测：叫谁的名字

**主题**：终幕不是成熟告白，而是“特别性”的低强度复测。赫萝要确认的不是信息，而是危机反射里罗伦斯是否把她放在不同位置。

## 短情节与回指
- 赫萝先照顾罗伦斯空腹的身体，带来面包和蜂蜜酒加牛奶的热饮（s49:9-22）。
- 第一问是“汝信任那姑娘到什么程度”。罗伦斯答得很商人：没有信任到预料诺儿菈可能带黄金逃走还照样交给她；因为商人本性会想万一（s49:23-36）。
- 第二问时，赫萝抓住罗伦斯衣角，小手颤抖，问她与狗、诺儿菈准备交手时，罗伦斯叫了谁的名字（s49:47-55）。
- 罗伦斯先说叫了赫萝，被识破为谎；再说不记得，但觉得肯定是赫萝，因为她名字短（s49:68-83）。
- 赫萝怒的不是答案，而是他当真这么认为：把“叫咱”解释成技术理由，等于又抹掉特殊性（s49:84-90）。
- 赫萝造复测场，让诺儿菈出现时罗伦斯叫名字；罗伦斯用喷嚏遮掉不可裁决的瞬间，随后等赫萝看向诺儿菈时补叫“赫萝”，说还是赫萝比较好叫（s49:93-116）。

## 简单分析
s49 与 s27 同构：

| s27 | s49 |
|---|---|
| 重行为：留盘缠 | 危机反射：叫谁 |
| 错误解释：个性使然 | 错误解释：名字短 |
| 赫萝要的：说“你是特别的存在” | 赫萝要的：在诺儿菈在场时仍选择叫“赫萝” |

终幕没有证明过去事实。罗伦斯也没有成熟告白。他做的是绕开“事实审判”，在当下补一次对赫萝有效的选择。这就是为什么它像回答又不像回答：它足够让两人继续旅行，不足以清掉全卷的不安。

## 边界
不要把终幕写成完美升温。它仍然笨拙、机巧、半开玩笑。但也不要说完全没有进展：赫萝已经能把不安拿出来问，罗伦斯也知道不能让事实裁决把她输掉。
