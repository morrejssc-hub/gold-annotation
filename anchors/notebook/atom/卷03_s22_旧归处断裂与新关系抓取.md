# 卷03 · s22 · 旧归处断裂与新关系抓取

回链：`notebook/锚_卷03.md`

## 事实观察

s22 中，赫萝独自读到狄安娜信里“古时已灭亡的城镇约伊兹”。她先说“咱啊……无家可归了……”，随后更明确地说：

- “咱变成孤单一人了。”
- “已经没有人在等着咱回去了，哪儿都没有。”

因此崩塌对象不只是地点。约伊兹承载的是旧关系结构：有人在等，自己仍有地方可回，前进仍有方向。

罗伦斯试图承接：“你不是有我吗？”原文说明这是“不带虚假的真心话”，且不是随便能说出口的话。但赫萝没有接住，追问：“汝是咱的什么人啊……不对，咱是汝的什么人啊？”罗伦斯答不上来。

此后赫萝滑向两个替代支点：

- “如果有了孩子，就会是两个人。”
- “有人……没错，有人爱着咱呐。”这里指向阿玛堤。

## 读法

s22 的顺序很重要：

1. 旧归处/旧等待者断裂。
2. 赫萝先抓罗伦斯。
3. 罗伦斯给出在场，但答不出“他到底怎么看她”。
4. 赫萝滑向“孩子”这种最低限度的二人关系。
5. 再滑向阿玛堤这个“有人明说爱我”的外部符号。

这不是赫萝在稳定状态下选择阿玛堤，也不是三角恋压力。她抓的不是阿玛堤这个人，而是“有人爱着咱”这件事。

## 她在确认什么

“咱是汝的什么人”不是在索取一个关系名词，而是确认罗伦斯对她的看法是哪一种。赫萝怕的东西，s22:81 自己说得很白：“汝喜欢可怜柔弱的小羊呐……一定觉得咱愚蠢得可爱呗？可怜得让汝觉得心疼，是呗？”——她怕罗伦斯的温柔是**居高临下的怜悯**，怕自己只是又一个被这个烂好人顺手善待的对象。这正是卷02“别把咱也算进天性使然里”的延续（[[卷02_主轴_别把咱也算进天性使然里]]）。

也因此，**单说一句“喜欢你”在 s22 未必够**：在她的恐惧里，“喜欢”恰恰可能就是那种混着怜悯、保护、对小羊的心疼的喜欢。她要确认的不是有没有“喜欢”这个词，而是这份在意是不是把她放在不一样的位置。

## 与 s35 的时间线

赫萝去找狄安娜，请她捏造“约伊兹其实有可能仍存在”的假消息，发生在 s22 崩溃之后。s35 里赫萝说明，她凭信件气味找到狄安娜，原本是想让狄安娜转告罗伦斯一个能让他更容易主动开口的消息。

这说明 s22 后赫萝的第一优先不是转投阿玛堤，而是修复罗伦斯这条线。她先道歉，罗伦斯退走；她又去找狄安娜造台阶。阿玛堤/婚书后续才变成“让罗伦斯有理由生气”的舞台。

## 边界

- “孩子”段落是崩溃态下的自毁式抓取，不应当读成稳定愿望。
- 阿玛堤在 s22 是替代符号，在 s25 以后才成为修复工程的工具。两个功能不要混成一个“她早有设计”。
