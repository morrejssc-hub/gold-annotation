## 1. 两臂范围切法差异

**两臂都判对了第一刀：本卷关系线是散点暗线、不套大弧，主线（商战/调查）不承重。** 这一点高度收敛，且都给了显式范围留痕、都回指 `canon/maintext/卷09.json`、都用 `canon_slice` 亲核——切法纪律两臂都达标。

主轴 scene 的具体选择高度重叠，但有可辨差异：

| | claude 臂 | glm 臂 |
|---|---|---|
| 共选主轴 | s00 / s02 / s08–09 / s20 / s23 / s28–29 | 同（s00 / s02 / s08–09 / s20 / s22–23 / s28–29） |
| claude 独有 | （把 s05–06 归梗概）| —— |

| 高潮 s30–33 | 明确判**不承重**（奇迹现场是芙兰线收尾） | 明确判**不承重**（高潮动作戏） |

**切法上的实质分歧（最值得并排看的一处）：glm 把 s05–06、s10–11、s34 收进主轴精读，claude 把它们归梗概。** 这不是优劣问题，是两种切法策略的差异：

- claude 切的是**关系动作的承重落点**（赫萝崩口/怒点/接住的那几句），把"铺垫"和"收尾"剥到梗概，主轴更瘦、更聚焦"压强打到两人身上的瞬间"。
- glm 切的是**关系机制的完整链条**，把怒气的"案发现场"（s10–11 出丑）和"破案"（s23 揭机制）一起精读，把犹古的镜像功能（s06）当独立承重段，把 s34"门外等"作为与 s23 怒气的对照收尾。

→ **两种切法各有所得**：glm 的 s10–11 并入让 s23 怒气有了"先因后果"的完整证据链（claude 把出丑现场压成梗概、只在 s23 回指）；glm 的 s06 精读挖出了 claude 完全没用的承重段（见 §3 新读法）。反过来 claude 不精读 s06，避免了把"犹古=镜子"也焊进关系主轴的风险。这是**互补**，不是谁覆盖谁。

**对高潮 s30–33 的判断完全收敛**：两臂都判奇迹现场不是关系承重处。这是本卷切法上最关键、也最容易被读者误抬的点（赫萝瀑布嚎叫制造"天使奇迹"很像高光时刻），两个异质模型独立都判它不承重——**这条切法判断因双臂收敛而置信最高**。

## 2. 读法收敛 / 分歧 / 互补

### 收敛（两臂独立都得、且都扛过对抗 → 本卷置信最高的几条）

1. **「散点暗线、压强外包给第三者」的总框架**。claude 叫"关系外包给三面镜子"，glm 叫"被外部情节盖住的散点暗线 + 第三者镜像"。措辞不同，骨架一致：两人之间无冲突，张力靠第三者（犹古/芙兰/卡特琳娜）反射回来。两臂都给了同一条边界警告——**手法统一 ≠ 心理动力统一**（claude"三面镜子照三条不同轴"；glm 读法D边界(d)"别因服务同一主轴就焊成一条"）。
2. **「代价校准 / 诚实报限」（s00:51 + s00:53）**。claude 细节①、glm V9-W2 各自独立标出，且都给同一边界：赫萝要的是"力所能及"不是"在所不辞"，**别读成承诺升级/trust 升档**。两臂对抗都判此条最稳（claude"最稳"、glm"扛过"）。**这是本卷双臂收敛 + 双臂扛过对抗的唯一一条，置信最高。**
3. **「芙兰是罗伦斯觉悟的镜子，不是赫萝处境的镜子」**。claude 细节④（觉悟/重量轴）、glm 读法B 各自独立得出，且都强调"别把芙兰抽象成赫萝镜像、会压掉寿命论差异"。两臂对抗都"扛过"。
4. **「s28 赫萝接住罗伦斯、不附和贬低」**。claude 细节⑥/候选B、glm 读法D表 s29 行 + 不要急八条③④，都读出赫萝"被说到痛处了呀"是接住而非考验。**但此条两臂都被对抗削弱**（见下分歧），故收敛但不升置信。
5. **「本卷无 trust 跃迁、是稳定档位上的参数细化」**。claude 第六节、glm 读法D + 不要急八条⑤，独立都判无跃迁。**但 glm 此条被 s29:87–88 反证削弱**，claude 未碰这点——见 §3。

### 分歧（两臂落点/侧重真不同）

1. **主轴的组织方式：claude「三轴并立、拒绝统一主轴」 vs glm「一条强主轴 + 多轴子项」。** 这是两臂最大的结构性分歧。
   - claude 明确**拒绝**把三面镜子合成一条统一读法（"三条不在同一轴上，别合成一条"），把无力（s08）/善终（s20）/重量（s28）当三条独立心理动力，只在叙事手法层共享。
   - glm 给了**读法D 强主轴**——"赫萝需要一个理由继续参与人类世界"，把 s00/s08/s09/s20/s23/s29 六点都兜进"参与的理由"伞下（再用自我轴/关系轴细分）。
   - **这不是矛盾，是粗细两个层级**：glm 的"参与的理由"伞，约等于把 claude"三轴"再往上抽一层找共名。但**glm 的强主轴恰被对抗削弱了边界(a)**（s23:135–139"帮忙归根结底为自己/为心安"把竞争心收编回"参与的理由"），说明这把伞撑得过宽、连"竞争心"都兜进来了。claude 的"三轴拒绝统一"反而更保守、更经得起对抗。**→ 倾向：保留 claude 的三轴分立作骨架，glm 的"参与的理由"可作一个待验证的上层共名候选（标存疑），不直接当主轴定稿。**

2. **赫萝怒气（s23）的读法侧重不同，且互补。**
   - claude 读法侧重**怒点的内容**（气的不是失败、是"偏偏在咱面前出丑你还无动于衷"+ 帕斯罗村自照"我也干了村民那种事"）。
   - glm 读法C/V9-W1 侧重**怒气的关系机制定性**——"替罗伦斯对第三方面子出气 = 关系内可追讨权的扩展形式"（接卷02"关系内可追讨权"），且明确反占有欲（s23:109 自我反思）。
   - **glm 这条是它最稳的一条（对抗判"最稳"），且给了 claude 没给的跨卷接口**（卷02 可追讨权 → 卷09 扩展为替第三方出气）。claude 这边怒气只作"读法一边界的内部摩擦反例"处理，没把它抽成关系机制。**→ 互补：glm 的"可追讨权扩展"是 claude 没有的关系机制候选，值得吸收（带 glm 自标的反例：未测"罗伦斯单独出丑赫萝是否同样气"）。**

3. **「被否定的正确答案」(s20:95–96) 的处理深浅不同。**
   - claude 把它单列为"留白引信"，反复设防"只确认存在、与寿命/善终有关，别用后续卷倒灌"，并把 s20"带着狼当心"做了三读并存（替罗担心/自照连累/回指被否定方案）。
   - glm 把它读成"否定了一个安全但分离的方案（赫萝变回狼留森林）"——**glm 在这里给出了具体内容猜测**（"语境暗示是赫萝变回狼形留在森林=安全但分离"），claude 则严守不填。
   - **→ 这是纪律分歧**：claude 守留白更稳（符合"别倒灌"纪律）；glm 的猜测虽标了"语境暗示"，但已在往里填具体内容，**采信时应降为 claude 的"留白不填"口径**，glm 的猜测仅作旁注记一笔。

### 互补（一臂有、另一臂无，可直接补进合并稿的）

- **glm → 合并稿**：① s06 犹古镜像段的承重读法（见 §3 新读法）；② s23 怒气的"关系内可追讨权扩展"机制定性（claude 无）；③ s00:38–40"两种坚强"的承重句（两臂正文都没充分用，glm 对抗才挖出，见 §3）。
- **claude → 合并稿**：① "三轴拒绝统一"的保守骨架（比 glm 强主轴更抗对抗）；② s20 三读并存的克制处理 + 留白引信纪律（比 glm 的具体猜测更稳）；③ 弱模式B"赫萝把对方锚回本来样子/不接受错位的尺"（glm 无此条，但被对抗标为单点样本，存疑）。

## 3. 并置才浮出的新读法

两臂并置后，浮出三处**任何单臂都没说清、但合起来才成立**的东西：

### 新读法①：「两种坚强」(s00:38–40) 是被两臂同时漏掉的主轴根 —— 置信中

glm 对抗自己挖出：紧贴"借口暖炉"前，文本明写"世上有两种坚强。一种是因为有想要保护的东西而坚强。另一种，则是没有可失去的东西时的坚强"（s00:38–40），并把赫萝归到**第二种（无可失去）**。**两臂正文都没引这段**（claude 正文未提，glm 正文也只在对抗里补）。

并置价值：这段是 claude"在场/参与即意义"（候选A）和 glm"借口暖炉=生存坐标"（V9-W3）**共同的、更靠上游的文本根**——两臂各自的弱模式其实都是"无可失去之人如何继续活"这一句的下游展开。**它能同时给两条弱模式一个共名，且这个共名是文本明给的（不是叠加 gloss）。** 这正是合并稿该抓的落点：不用"参与即意义"也不用"生存坐标"当顶，用文本自己的"第二种坚强（无可失去时的坚强）"当根，"借口暖炉/参与即安慰"是它的具体形态。**建议合并稿补 s00:38–40 为承重句。**

### 新读法②：怒气(s23)与接住(s28)是同一关系权能的两面 —— 置信中

单看任一臂看不出，并置后浮现：
- glm 把 s23 怒气定性为"把罗伦斯的事当自己的事 / 关系内可追讨权扩展"。
- claude 把 s28 接住定性为"赫萝作接住者、把罗伦斯锚回本来样子"。
- **并置发现**：s23"替你的面子出气"和 s28"被说到痛处了呀+你做不出卖死人"，其实是**同一个"你的事就是我的事"权能**的两种方向——一个朝外（替你对第三方出气），一个朝内（把你从自我否定里拽回）。glm 的"可追讨权扩展"和 claude 的"接住者"是同一枚硬币。**这条比两臂各自的版本都更统一，且连接处有文本支撑**（两处都是赫萝把罗伦斯的处境当自己的事处理），不是强焊。可作合并稿的一条候选关系机制（标候选·锚定正典·定稿归人）。

### 新读法③：s29 是「考验形态的过去式余烬 + 接住的实质」—— 置信中高（两臂对抗在此处罕见地交汇）

**两臂对抗各自独立指向同一处文本 s29:87–88，是本轮最强的交叉信号**：
- claude 对抗：用 s29:87–88 削弱自己臂的"赫萝不考验"（细节⑥），结论"考验张力存在但已退为过去式，落点是接住"。
- glm 对抗：用 s29:87–88 削弱自己臂的"无 trust 跃迁"论断，结论"存在一个可观测的信任状态变化点，但是罗伦斯主观感受、未必等于赫萝侧跃迁"。
- **并置发现**：两臂从相反的命题出发（一个说"不考验"、一个说"无跃迁"），却被同一句 s29:87–88 同时削弱——说明这句话同时承载了**"考验形态"和"信任变化标记"两层**，是本卷一处被两臂正文都切窗漏掉、却被两臂对抗同时捞回的承重句。合并稿对 s29 的定性应是：**"答错就离开"的考验张力此刻已退为过去式（s29:88"前不久或许还会这么想"），实质落点是接住（s29:93"可不许汝失败哦"=有条件应允）；同时这个"从前会担心到现在不担心"的过去式标记，是本卷唯一带"信任已稳"痕迹的句子，但属罗伦斯主观、不构成赫萝侧 trust 跃迁。** 这比两臂正文（claude"赫萝不考验"、glm"无跃迁是参数细化"）都更准。

## 4. 逐条读法 + 置信度

**"高"= 双臂独立收敛 + 双臂均扛过对抗；"中高/中"= 单臂或收敛但被削弱；"存疑"= 单点/被削弱较重/纪律风险。**
