## 0. 一句话定位

两臂都把卷07 读成「关系线被伊卡库商战盖住的**散点暗线**」，主轴框架高度一致——但**第一刀切的厚度差一倍**（Claude 主轴 8 个 scene，glm 16 个），且两臂各自漏/补了对方没看见的硬证据（Claude 独有 s24，glm 独有 s42/s44/s52/s33/s40）。并置后浮出的真正增量在第 3 节。

## 1. 第一刀：范围切法并排

| | Claude 臂 | glm-5.2 臂 |
|---|---|---|
| 主轴 scene | s01 / s16 / s18 / s24 / s35 / s47 / s53–54 / s60（**8 个**） | s01 / s07 / s13 / s16 / s18 / s22 / s29 / s33 / s35–36 / s40 / s42 / s44 / s52 / s55 / s60（**16 个**） |
| 切分依据自陈 | "没有连续关系大弧"，深挖**吃醋暗线 + 两处赫萝主动重设位置（s16/s18）+ 艾普反面镜**，其余一句带过 | 同样判"散点暗线"，但判**"几乎每个关系动作都被外部压力催逼出来"**，于是把被压力催出的每一拍都收进主轴 |
| 切法性格 | **窄而深**：少数窗口逐句精读，明确把 s12/s22/s40/s42/s44 这些归为"日常色温样本"或梗概，不进主轴 | **宽而密**：把日常色温（s07/s13）、政治教练（s22/s40）、脆弱时刻（s44/s52）全部抬进主轴，几乎一幕一锚 |

**第一刀的实质分歧**：不是"谁漏了"，而是**对"催逼"的态度相反**。
- Claude 把"被商战催出"当成可压缩的背景，只留催出后的**关系结晶**（s16 立规、s24 吃醋、s35 坦白），政治线一律梗概。
- glm 把"催逼"本身当成**关系动作的发生学**，所以 s29（恐慌→制止）、s40（政治教练）、s44（后悔推他入局）这些"压力现场"对它就是主轴——它要留住"关系动作是怎么被逼出来的"那条因果链。

两种切法各自的代价：Claude 的窄切**漏掉了 s42/s44/s52 三幕**（牵手、月下"配角"自白、港口崩溃），其中 s44/s52 是本卷情感最脆弱的两处；glm 的宽切**漏掉了 s24**（本卷最直白的吃醋显形），且 16 幕铺开后单幕精读密度被摊薄。

## 2. 事实/scene 号分歧，回正典亲核

### 2.1 s24 — Claude 独有、glm 漏（裁决：Claude 对，glm 漏了一整幕硬证据）

Claude 臂把"赫萝让柯尔捂耳朵、揪罗伦斯耳朵、'闻闻味道就清楚艾普喝了你的酒'、'骗她说出来吧，汝不是连咱这个贤狼都骗了吗'"全部系在 **s24**。glm 臂主轴与梗概里**都没有 s24 这一幕**（它把 s23–28 整段压成"情报汇总、铜币之谜、艾普来信约见"一句梗概）。

亲核 `-s 24`：原文确认这一整幕在 s24——
> "骗她说出来吧。汝不是连咱这个贤狼都骗了吗？"……"小柯尔，汝把头低下去把耳朵捂住。"……"对于别人吃了些什么东西，汝这样的人只有亲眼看到才知道。不过对于咱来说，只要闻闻味道就清楚了。"……（旁白）"罗伦斯多少也注意到了。赫萝非常不安。狼之骨的传说带着些许现实意味……"

**裁决：Claude 对。** s24 是本卷吃醋暗线**最冷峻、最直白**的一拍，且原文旁白当场点破"吃醋是表层、底下是对狼骨传说现实感的不安"——这是 Claude 读法二（吃醋=怕不牢的出口）的核心文本证据。glm 把它压进梗概，丢了一处一等证据。**这是本次对比里最该回填进合并稿的事实补丁。**

### 2.2 "咱不去/把咱扔在这里就跑" 的 scene 号 — Claude 标 s53–54，glm 标 s55（裁决：glm 对）

亲核 `-s 55`：
> "唔，那么，汝可以把咱扔在这里就跑吗？"……（罗伦斯）"柯尔。""好的，请交给我吧。"……（赫萝）"行了，快走吧。"……罗伦斯奔跑着。向着教堂，拼命奔跑。

**裁决：glm 的 scene 号更准。** 赫萝拒绝同去救艾普（"咱可不想看到汝在别的雌性面前大显身手"+"把咱扔在这里就跑吗")发生在 **s55**，紧接罗伦斯才奔向教堂。Claude 把它写成"s53–54 末尾"，scene 号偏前一格。读法本身两臂一致（吃醋外壳包着"我留下不当你弱点/不被牵连"的后手），只是定位有偏差。

### 2.3 艾普"叫罗伦斯名字" — Claude 全系在 s60，glm 同时标 s49 与 s60（裁决：两臂互补，glm 多抓了 s49 这一处）

Claude 臂把"艾普报全名、第一次叫他名字'克拉福·罗伦斯，能遇到你真好'"系在 **s60 终幕**。glm 臂在读法 B 与候选 V7-C3 里把"叫名字"**主要系在 s49**（"认真称呼我的名字的只有爷爷和少数奇怪的人"），s60 作余温收束。

亲核 `-s 49`：原文确认 s49 已出现完整的叫名字——
> "那么，我想问问称呼了我名字的行商者克拉福·罗伦斯。"……（艾普）"认真地称呼我的名字的只有爷爷和少数奇怪的人。"……（罗伦斯）"你希望有人叫自己的名字，是吧？"

亲核 `-s 60`：s60 是**第二次/告别复述**（"克拉福·罗伦斯，能遇到你真好"+报全名）。

**裁决：互补，不互斥。** "有人叫她名字"这条线**横跨 s49 和 s60**：s49 是艾普**自陈渴望被叫名字 + 罗伦斯当场点破**（情感内核），s60 是**告别仪式化复述 + 报全名**（闭环）。Claude 只抓了 s60 闭环、漏了 s49 这个**情感源头**；glm 抓了 s49 源头。合并时两处都该留，且 s49 是"艾普镜像"读法更硬的锚（赫萝在旅途中已拥有的"有人叫名字"，正是 s49 艾普明说自己没有的）。

### 2.4 s42 牵手、s44 "配角"自白、s52 港口崩溃 — Claude 全漏，glm 有（裁决：glm 补了三处真实关系证据）

Claude 主轴与细节里**没有** s42（看完伊卡库后赫萝"悄悄把手塞进罗伦斯掌心"）、s44（月下"咱后悔了"+"咱终归是个配角"）、s52（罗伦斯呕吐、"为自己没被带走而松了口气"的自我厌恶 + 赫萝无声在场"一起旅行的只有你哦"）。glm 把这三处都列为主轴并精读。

亲核 `-s 52`：原文确认 glm 引文准确——
> "这并不是无力感。而是无法忍受难以置信的自我厌恶。罗伦斯松了口气。为自己没有被奇曼带走而松了口气。"……（赫萝）"需要智慧的话，咱借给汝吧。"……（罗伦斯）"可是，一起旅行的只有你哦。"

**裁决：glm 补的是真证据。** 这三幕都是文本实有的关系动作，Claude 的窄切把它们当背景压掉了。尤其 s52 的"松了口气→自我厌恶"是罗伦斯本卷最赤裸的自我暴露，s44 的"配角"自白是赫萝主动距离管理的硬锚——两处都不是商战物流，是关系正文。**合并稿应以 glm 的 s42/s44/s52 为底补回。**

### 2.5 无实质事实冲突、两臂一致的部分（确认无须裁决）

s01（"你肯为我生气，谢谢你"+契约语言）、s16（三怒结构、"相互支撑"内心独白、"供品"句、被排除的寂寞旁白）、s18（手下/缰绳/学差遣人）、s35（伊卡库旧伤、"现在的咱有汝在"、柯尔是"重石"）、s60（阿比草吻别留香→当场算账）——两臂引文与 scene 号一致，仅详略不同。**s16 的"供品=祈祷必需品"句、s35 的"重石"句两臂都抓到了，是本卷公认硬锚。**

## 3. 并置才浮出的新读法（本步真正要交付的）

> 以下是两稿并排后才显形、任一单稿看不出的结构。**均为读法层，标"非定稿"，是否升格/合并归人。**

### 新读法 A：「供品」与「重石」是同一个边界机制的两面——一面拒绝被供、一面主动设防

单看 glm 稿：s16"供品"句（拒绝被单方面上供）和 s35–36"重石"句（用柯尔维持贤狼身份、不越线）是它读法 A 和读法 C 两条**分开**的轴。单看 Claude 稿：没有"供品"这条线（Claude 没把 s16:169 的供品类比拎成独立机制），"重石"被读成"柯尔 vs 罗伦斯两种关系"。

**并排才浮出的**：两句其实咬合成**同一个距离控制系统的输入端和输出端**——
- s16 赫萝**对罗伦斯**喊"别把我当供品"（**要求对方别替我决定**＝拉近、要求被卷入决策）；
- s35–36 赫萝**对自己**设"柯尔当重石、不可越线"（**主动约束自己别太靠近**＝推远、管理寿命差代价）。

同一个赫萝，**对外要求被卷入、对内要求别失控**。glm 把它们判成"不互相生成的独立轴"（其读法收尾明说三轴各自独立），但并排 Claude 稿对 s35 的"卸下贤狼说真心话只对罗伦斯"后，会发现：**"重石"防的恰恰是 s16 索要的那种亲近过头**。这条咬合关系任一单稿都没说出来——**赫萝在卷07 同时踩油门（要商量、要被依靠）和踩刹车（设重石、当配角），张力不在她和罗伦斯之间，在她自己内部。** 这是给"怕分离"主题的新落点候选：怕分离的人不是单纯想靠近，是**一边索要卷入、一边给自己留撤退距离**。

### 新读法 B：「叫名字」是艾普镜像的轴心——而赫萝整卷恰恰不被罗伦斯当面叫名字

由 2.3 的事实裁决长出来。glm 抓到 s49"叫名字"是艾普的核心渴望，Claude 抓到 s60 阿比草吻别闭环。并排 + 亲核 s49 后浮出一个**任一单稿都没点的对照**：

艾普要的是"有人认真叫我名字"（s49），且她报出真名换罗伦斯一句"我不会忘记艾普·布朗这个名字"——**这是艾普整条人物弧的终点**。而回看赫萝线：罗伦斯对赫萝几乎从不"郑重叫名字"，s35 赫萝亲口说罗伦斯是"看到咱样子先想摸尾巴的大笨驴"（**反郑重**），s60 处理吃醋也是闻味道+扔香草（**非语言**）。

**并置新读法**：艾普镜像不止是"孤独 vs 有同伴"的对照（两臂都说了这层），更精确的是——**艾普求的是"被郑重命名"这种仪式化确认，而赫萝和罗伦斯之间恰恰是"不靠郑重命名"的关系**。赫萝不需要罗伦斯郑重叫她名字，因为他们用的是摸尾巴、扔香草、揪耳朵这套**非仪式的身体语**。艾普临终要一句郑重的名字，正反衬出赫萝拥有的是**不需要仪式就成立的亲密**。这条"仪式化确认 vs 非仪式亲密"的对照，比"孤独 vs 有伴"细一层，是 s49+s60+s35 三处并起来才显形的。

### 新读法 C：本卷"软弱"有两个独立来源，两臂各抓一个，合起来才是完整的双向翻转

Claude 稿主打**赫萝向罗伦斯索取软弱/依赖**（读法"赫萝主动要的是他的依赖/商量，不是他的体贴照顾"，落 s16/s18/s35）。glm 稿主打**罗伦斯侧被允许软弱**（候选 V7-C2，落 s16:139–143 内心翻转"罗伦斯应该拿出勇气变得软弱"、s52 崩溃后仍能说"一起旅行的只有你"）。

**并排才完整**：卷02 强弱线（"赫萝不该被当弱者保护"）在卷07 被**双向翻转**——
- glm 那半：**罗伦斯**意识到自己也该被允许软弱、该说"没有你的支持不行"（s16 内心独白，Claude 稿引了这段但没拎成"罗伦斯侧翻转"）；
- Claude 那半：**赫萝**主动索取的是罗伦斯的软弱/依赖而非照顾（glm 稿没把这条单独拎出）。

合起来是一个**对称命题**：卷07 里两人都在要求对方"别只当强者"——罗伦斯学着示弱求助，赫萝要求被依靠而非被保护。任一单稿都只抓了对称的一半。**这条对称性是 s16 一幕内同时容纳两个翻转方向（赫萝逼他示弱 + 罗伦斯内心决定示弱）才成立的**，是本卷相对卷02 的真实推进点候选（但注意：s16 是赫萝单方索求 + 罗伦斯单方内心决定，文本没说此后罗伦斯真做到了——边界归人审）。

### 新读法 D（弱信号，存疑）：glm 的"宽切"无意中暴露了一条 Claude 窄切看不见的节奏——关系动作总卡在"罗伦斯政治受挫"之后

glm 把 s22/s29/s40/s44 这些"政治受挫现场"全收进主轴后，并排 Claude 的窄切，浮出一个**节奏**：本卷几乎每一次关系推进都**紧跟在罗伦斯一次商战/政治挫败之后**——s16 接幻灭、s29 接恐慌、s44 接被推入不擅长的局、s52 接救艾普失败。Claude 因为把政治线压成梗概，**看不见这条"挫败→关系结晶"的固定节拍**。

**存疑标注**：这可能只是 glm 宽切的副产物（收得多自然显得有节奏），也可能是本卷真实的发生学结构（外部挫败是关系动作的固定触发器）。是否成立、是否值得升格成"触发条件"，**归人审**——这里只记录"两种切法密度差本身能暴露不同结构"这一方法论事实。

## 4. 给人审的并置清单（不裁决、不排名）

- **事实分歧**：①s24 吃醋显形（Claude 有/glm 漏，裁决 Claude 对，建议回填）；②"咱不去"在 s55 非 s53–54（glm scene 号更准）；③叫名字横跨 s49+s60（两臂互补，glm 多抓 s49 源头）；④s42/s44/s52 三幕关系证据（Claude 漏/glm 有，建议以 glm 为底补回）。
- **范围分歧**：窄深（Claude，8 幕）vs 宽密（glm，16 幕）；分歧实质是对"商战催逼"是背景还是发生学的相反态度。
- **读法分歧/互补**：新读法 A（供品×重石＝同一边界机制两面）、B（叫名字：仪式化确认 vs 非仪式亲密）、C（软弱的双向翻转，两臂各半）、D（挫败→关系结晶的节拍，弱信号存疑）。
