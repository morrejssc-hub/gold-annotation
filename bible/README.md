## 方法：锚点日记 → 后验浮现 → bare-diff 结晶

文学角色之所以"立体"，是同一幕容得下多种自洽读法。机制卡若过早择一，就把角色**坍缩**成固定方向。故采**自底向上**路线：

### 1. 先攒锚点日记、不收敛

每则锚是读原文时留下的田野笔记，格式大致为（参考，不必死守）：

- **本段之前已经在场的东西**：不是机制，只是读这段时不能忘掉的前史和语境。
- **这几幕直接发生了什么**：可引回原文的事实观察，不加解释。
- **值得盯住的细节**：指认一个现象，往下想一层但停在疑问，不下结论。这是田野日记最核心的层——比纯事实多一步思考，比读法少一步裁决。
- **暂时并存的读法**：几种可以同时成立的解释，各挂一个标题，互不裁决。段落体，不是标签。
- **现在不要急着抽象成什么**：列出诱人的漂亮规则，然后说明为什么太早。提醒未来的读者不要被这份语境锁死。
- **可暂存的弱模式**（可选）：如果确实有一条带前史条件的临时读法，可以小心地写下来，标明"临时、非定稿"。

关键原则：**保留复数解释的厚度**，不把角色坍缩成单一方向。每条读法内部也要警惕标签化——如果一个词（比如"善良"）有变成标签的危险，就地展开它到底意味着什么。

### 2. 后验浮现

锚攒多后横比，**跨锚复现**的解释线才是候选机制。单锚分不开的多解不强行选。

### 3. 过 bare-diff 才写进 policy.md

候选机制还得对裸基线有增量（裸模型在此漂、它能掰回来）才进 `policy.md`。**policy 越薄，角色越立体**——机制是修正项，不是生成器。

## 纪律

1. **机制正文（Policy）由人定稿**；Claude 采正典、做结构化追踪、给正典锚定的候选抽象（辅助论证，教训5）。
2. 机制写成**可迁移的生成过程**，标支持场景 + 复杂化反例，不停在"骄傲/嘴硬"这种标签层（纪律4）。
3. 任何 Policy 改动须能与 **bare** 对比（消融阶梯，同模型同参数、唯一变量=圣经；DESIGN §0.1/§6）。
4. 关系对象加字段须过准入测试（DESIGN §0：能构造最小翻转探针对才准入）。
