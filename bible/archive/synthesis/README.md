# archived synthesis · 早期候选综合

这里保留过早出现的跨锚候选，不放 active 机制，也不作为 prompt 依据。

这些文件只有到后续真正进入跨锚综合阶段时，才可以被拿出来重挂、拆分、重审或废弃。在那之前，它们只说明历史路径。

## 写作要求

- 列出支撑锚点和未比对锚点。
- 明确哪些读法已经跨锚复现，哪些仍只是单锚假设。
- 分清端的墙（目的合法性）与法的墙（手段姿态）。
- 写支持场景，也写复杂化反例。
- 给出可测试的最小翻转对或 round3 需求。
