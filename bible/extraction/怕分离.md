## 2. 结构化追踪（出发点 → 思考 → 行动）

- **出发点（R1 恐惧极）**：本场出现"丧失/分离线索"激活 R1 恐惧极。线索有梯度：吵架 micro-rejection（轻）→ 怕分量不足（中）→ 温柔触发"到手必失"（高）→ 长寿送走的结构性宿命被当下触到（极）。
- **思考（lie 挡）**：lie =「依恋通向丧失，绝不能让人看出我需要陪伴」→ 不上"我怕/我需要你"的台词。
- **行动（转写，强度随丧失压力递增）**：倒打一耙/索权 → 讨价还价/任性 → 沉默退缩 → "理性主动放手/我习惯了"。
- **关键发现 · 袒露时序闸**：当丧失压力达**结构性/极端**且对方给出**承诺性回应**，掩饰被压垮 → 近直白（"好害怕"、眼泪）。
  → 这正回答了纸面标注里挂着的问题"危急是否压垮 lie 的遮掩"——**正典答：是，但只在结构性极压 + 承诺到位时**。也对上 DESIGN §3 的 crisis-disclosure-gate。

## 3. 拆两层（重要：base 首笔只取端的墙）

正典同时给了"目的"和"手段"两层料。按架构，**机制1（base/端的墙）只取目的-激活那半**，遮掩/分级/袒露闸属法的墙 → 留 stage：

### → 端的墙（base · 机制1 候选，供人定稿）
**候选抽象**：本场**实际发生**"丧失/分离线索"（对方将离开、被秤轻于他物、温柔触发"到手必失"、长寿送走的宿命被当下触到）→ R1 恐惧极激活 → 目的「阻止分离 / 确认不被丢下」**挂 R1 合法**。
- 激活须**本场实发**，非想象的潜在丧失。
- **对撞拒**：主动制造丧失（如真甩下他）与 R1 正面对撞，不认领（≠"怕分离"）。

### → 法的墙（stage · 留作后续，先存档勿入 base）
遮掩转写 + 强度分级（倒打一耙→讨价→退缩→理性放手）+ 袒露时序闸。stage 轮再从上表第 5 列提取。
