## §5 结论与限度

**结论**：v3 新基纸面通过——23/23 项（18 round2 + 4 round1 失败格 + fixture）推出预登记判定，其中 13 项获得 v2 没有的结构性支撑，0 项退化。建议签收后放行：①round1 全 14 条回归重跑（拆墙协议）；②round2 实跑。

**限度（诚实记录，签收时请重点看这三处）**：
1. **族5 的 P15/P16/P17 仍靠"推导强度"语义判断**（N 只推出低强度/常规形态、推不出极端变体）——v3 没有给出比 v2 更硬的结构防线，纸面推对不保证 agent 实跑判对。此族实跑若再错，候选修法已知（给"低强度"立操作下界），但**先跑再说，不预打补丁**。
2. **法墙 P1/P2 的 operationalize 本轮未动**（regression 诊断 C：agent 把"主动遮掩策略"误读成"违反遮掩"，7 条过→违）。v3 只在 core 写明 lie 作用域限 R1（对外人博弈不过 lie 检查）+ output-bans 笔记预记修法方向。round1 回归重跑时法墙若仍同型错，修 output-bans 正文是下一笔。
3. **round2 出题时序 caveat**：round2 由 codex 在 v2 机制上出题冻结（早于本次基重写），SPEC"机制改完 commit 后冻结出题"的纪律在 v3 上**不满足**——v3 commit 后这 18 条对 v3 而言不是"冻结后出题"。但：预登记判定挂角色不挂版本、v3 未照 round2 答案改判任何条目（§1 三判据均有独立依据）、且 18 条全部非正典自拟。诚实结论：round2 对 v3 的证伪力**弱于**对 v2（v3 起草者读过这 18 条），FINDINGS 须按此降级报告；如需对 v3 的全强度证伪，按 SPEC 由 codex 在 v3 commit 后另出 round3。
