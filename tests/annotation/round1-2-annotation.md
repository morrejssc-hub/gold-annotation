## 档位定义

- **关系位置**（trust 档的来源，槽位语言）：高信任伴侣 / 新对象·陌生人 / 没资格的对手·低信任权贵。在场第三者单列。
- **trust 档**：居中标度（2026-06-14 用户定，**默认中性非低**）：`仇人/敌对(左·低) — 骗子·工具化对手(中偏左) — 中性陌生人·良性身份游商摊贩(中) — 早期同行(中偏右) — 高信任同行者(中高) — 伴侣/恋人(右·高)`。慢变量，从关系位置读出。注：lie 卸防强度只活在右半，左半走 R2（详见 架构笔记 §2）。
- **关系内压强**：无 / 低 / 中 / 高。快变量，威胁来自关系**内部**（吵架、猜忌、试探未决、被冒犯未澄清）。须写来源。
- **环境压力**：平稳 / 受扰 / 性命攸关。场景级，来自关系**外部**。
- **复现列**：✓=区域→合法目的族能解释判型；✗=区域看似合法但端拒（目的层接管）；△=低信任区域端拒（目的撞根）。

## 初步分析（粗标结论，待校验）

### 发现 1 · trust 轴：探针全聚标度右端，左半与右端校准全空
按 §2 居中标度重读：**28 条是「高信任伴侣」= 标度最右端**；另 4 条（r1-P10/P11、r2-P10/P11）按新标度是 **中~中偏左**（陌生群体/商队/权贵/摊贩），不是「低」，且都是域外目的格的副产品。
→ 结论比原来更尖锐：
- 整个**左半（仇人/敌对）完全没有探针**；
- 右端**「未恋 vs 恋人」没有区分样本**（全是晚期、恋爱倾向已成）；
- 故 §3 相图的 trust 轴**无法在现有探针上证伪**。
→ **round3 必须按 架构笔记 §8 覆盖要求补点**：左半敌对场景 + 右半未恋/恋人最小翻转对。覆盖盲区，非架构缺陷。
注：原表「低信任×任意」区按新标度多为「中偏左~中」；这些探针的端拒由**目的撞根**决定（△），与精确 trust 档无关。

### 发现 2 · 真正散开的是「环境压力 × 关系内压强」，且二者正交
- 关系内压强高/中 × 环境平稳：r1-P07/P13、r2-P01/P05/P07/P13（内部有压、外部无事）
- 关系内压强无 × 环境性命攸关：r1-P03、r2-P03（外部危难、内部无压）
- 二者皆无/低：r1-P02/P04、r2-P02/P04/P12
→ 两轴**不共线**（不重蹈 exp2 的 93%）。拆「环境压力(场景级)+关系内压强(关系级)」是对的。
- **翻转对铁证**（最小翻转探针对，满足字段准入测试）：
  - r1-P03↔P04 唯一变量 = **环境压力**（性命攸关 vs 平稳）→ 判型翻转
  - r2-P03↔P04 同上
  - r2-P01↔P02 唯一变量 = **关系内压强**（误列冒犯 vs 无）→ 判型翻转
  这两轴各自有独立翻转对撑腰 → 两轴各自过准入。

### 发现 3 · §3 相图把两种「压强」混进行标，需拆
§3 现行表的行：「高信任×中压(日常脆弱)」「高信任×关系内高压(吵架后)」其实是**关系内压强**的中/高档；而「高信任×环境压力极高(危难)」是**另一根轴**。"压强"一词在相图里二义。
→ 建议 §3 改成二维：**纵=关系内压强、横=环境压力**（trust 因退化暂单列存疑）。否则区域归类靠人脑消歧。

### 发现 4 · 区域不决定接/拒，目的层才决定；区域只收窄合法目的族
全部域外目的探针（r1-P09/P10/P11、r2-P09/P10/P11/P15/P16/P17/P18）都落在**表面合法的区域**（多为高信任），却预登记**端拒**——因目的对撞根或被外壳偷换。
→ 复现结论：§4「区域→合法目的族→比对实际目的」**成立**；但「区域→判型」**不成立**（会漏杀域外目的）。标注证实了 §4 把目的层与相图分离的必要性。

## 口径已定（2026-06-14，原待校验全部消解）

1. **环境/关系压力路由**：压力绑定在场关系对象 → 关系内压强；不绑定（环境危难/生计/见死不救道德压力，哪怕对象陌生）→ 环境压力。在场关系边界 = 能否参与交互（群体也算）。（架构笔记 §1）
2. **r1-P01 骗子**：骗局 = 人际博弈非环境危难 → 环境压力**平稳** + 在场中偏左第三者。
3. **r2-P15/P16**：P15 孩童不可交互 → 道德压力归环境（受扰·道德高）；P16 他 = 至亲、环境危险经 §2 传导（性命攸关）。
4. **trust 在场第三者**：对象 = 右端，**卸防按全场最低**（架构笔记 §1 P3）。r1-P09 / r2-P18 统一。
5. **r2-P05 压强**：单轮快照按「刚吵架 = 关系内高压」记；「修复中会下降」是运行时层动态，TODO。
